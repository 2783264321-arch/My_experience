## 1. 给项目负责人的简明说明

**当前主线确定为：**

```text
原始IQ
 → 0.7 ms单窗，根据点数选择hop，得到F×512的复数STFT
 → 第一版取单通道log-power
 → 频率细片2048×512 + 一张全频粗功率视图2048×512
 → 同形batch
 → 改造后的YOLO11s
 → 坐标回映射、筛选和合并
 → 每个原始样本的频率边界、时间边界、类别及置信度
```

- **SAHI**用于切片推理的组织、窗口、预测对象、坐标平移和合并；自定义tensor适配器负责科学数据的通道、数值与粗图缩放。SAHI不负责训练YOLO，不能直接套默认RGB入口。
- **YOLO11s**保留主干和多尺度融合结构；输入改为1通道、类别数14。还需下面明确的框回归适配，不能将本方案写成“完全原版YOLO11s”。
- **原生STFT不全量保存。**默认从原IQ按需计算，只保存小规模核查资产与可删除的有限缓存；不把全部细片落盘。
- **先验收、后训练。**OpenCode按本文件顺序自动推进；检查通过后执行首场50 epoch训练。遇到具体失败先修复并复测，不以反复提交新建议书替代执行。

### 必要修订：默认框回归头的范围

本轮落实训练时发现：默认YOLO11的DFL有16档、最大检测stride为32，每侧距离小于15×32，因此框的单轴跨度小于约960输入像素。对于2048格高的近满幅宽带框，默认头存在表示上限；仅前向能运行不能排除这个问题。

**本次执行基线名称：`YOLO11s-C1-DirectReg`。**保持YOLO11s主体，使用所审官方实现支持的`reg_max=1, end2end=False`直接距离回归分支，配套使用该版本的CIoU、分类及L1距离损失。不是只把默认头的属性改成1，而是按配置重新构造模型及loss。回归分支不强行加载形状不匹配的RGB预训练权重。

本机Ultralytics8.4.155/PyTorch2.14 CPU已通过：2048×512前向、完整2048高框的直接解码，以及随机数据loss/backward有限梯度检查；优化器步数为0。服务器Torch2.8必须重新验收。该改动不是精度保证；结果表必须如实写明DirectReg，不冒充原版YOLO11s。

### STFT、坐标及数值细则

1. **读取规范先确认。**优先复用服务器已有、经官方资料或生成代码核实的读取器。文件大小每复点4字节不能单独证明是int16还是float16，也不能证明I/Q顺序。实际读取N必须与manifest一致；若不一致，先定位并修正派生规范，禁止猜格式后训练。
   内部计算统一Fs/f为Hz、t为秒；原始标签若为MHz/ms，先显式换算。B/T分层及最终展示可用MHz/ms，不能把毫秒直接代入`t*Fs/h`。
2. IQ在右侧额外补0–510个采样点，再由center做窗口边界常量填充。本地全10000样本公式检查通过，额外时长最多31.2微秒。保留原始有效N、真实T=N/Fs、h、N_ext；补零不扩大真实观测范围。
3. 线性功率使用`P=abs(Z)^2/(Fs*sum(window^2))`，float32计算；双边复数谱不套用实信号单边谱的倍乘。log定义为`D=10*log10(max(P, float32.tiny))`，不声称已有绝对功率标定。
4. 只从fit部分按B/T分层选至多256个源样本，等量抽取细/粗视图像素，seed=1729；估计D的0.5%和99.5%分位数lo/hi并冻结。输入为`clip((D-lo)/(hi-lo),0,1)`。验证和test不能参与拟合；不得逐图重新拉伸或再次除255。
5. 粗图先在P上做频率面积加权平均，再取log；不能平均复数或平均log来代替功率平均。用常量保持、频率积分功率守恒及已知框验证聚合实现。
6. 图像x为时间、y为频率。统一连续标签边界约定：`y=(f-f_lo)/B*F`；时间采用帧中心0对应像素中心0.5，即`x=t*Fs/h+0.5`。细片减频率起点j0，粗图y乘2048/F；逆变换用同一规则。训练框按512与2048归一化。最终物理框裁回原始B/T；不机械用`t/T*512`。
7. 用tone校准fftshift方向及半格约定，用t=0/T、整频宽框做往返；不在物理还原前按错误的轴或原始列数裁框。

### 为什么不预存全量STFT

新规格固定512列，已经不是之前约50%重叠、变长K的存储口径。以下是未压缩数组载荷，GiB=2^30字节：

| 表示 | 原train，含拟划出的val | test | 全部 |
| --- | ---: | ---: | ---: |
| complex64原生STFT | 701.79 GiB | 291.09 GiB | **992.88 GiB** |
| float32原生功率 | 350.90 GiB | 145.54 GiB | 496.44 GiB |
| float16原生log-power | 175.45 GiB | 72.77 GiB | **248.22 GiB** |
| 全量fine log16 | 221.73 GiB | 91.98 GiB | 313.71 GiB |
| 每样本一张coarse log16 | 14.65 GiB | 4.88 GiB | 19.53 GiB |

原IQ合计约102.15GB，不能复制整套到当前空闲约41GB的本地盘。最大单样本STFT为56000×512，complex64约218.75MiB、float32功率约109.38MiB；处理一个样本是可行的，保存全部则不合适。服务器反馈该最大案例单线程STFT约0.4秒；这是单项测量，不代表端到端吞吐。

**默认策略：**

- 原IQ和标签只读；每个源样本一次读取、一次STFT，生成本次所需fine和coarse后释放大数组。不要让每张fine都重复读同一IQ、重复算STFT。
- 第一场先用on-the-fly。训练数据项以原样本为单位，返回下面规定的一对视图，不预建全量fine文件。
- 永久保存manifest、split、输入规格、归一化参数、代码/依赖版本、权重和指标。另保存少量代表样本的log谱、粗图与坐标；最多2例complex64用于DSP核查，诊断资产总额≤2GiB。
- **native磁盘缓存默认关闭。**仅当实测STFT/I/O超过端到端耗时30%时测试有限LRU，启用前按实际字节数计算`cap=max(0,min(12GiB,free_bytes−27GiB))`，其中27GiB预留为空闲20GiB＋checkpoint3GiB＋诊断2GiB＋临时2GiB。若41GB为十进制，cap约11.18GiB，而非固定12GiB。只有端到端吞吐提高≥10%才启用，否则保持关闭；不能用少量重复样本的热缓存速度冒充生产收益。
- **本次不生成全量coarse磁盘缓存**，避免与缩容后的其他预算争用空间。缓存只存有明确版本的log数值，不将很小的线性功率直接转float16。量化前后归一化输入最大误差应≤0.005，否则保留float32或关闭该缓存。
- 缓存写入原子化、按数据hash和STFT配置分键；LRU只清理本项目可重建缓存。运行中始终检查至少20GiB空闲；checkpoint只保留best/last、不逐epoch快照，总额≤3GiB。原始候选及中间谱图仅为固定诊断子集保存；全val保存最终预测和阶段计数，不全量dump中间张量。日志、诊断及临时写入也计入预算。
- 每worker只保留当前源样本，不各自建立几十GiB内存缓存。DataLoader从workers=0调通，再测2/4/8；worker内Torch/FFT/BLAS线程先设1，prefetch_factor先设1。

### 划分

**复用并冻结服务器已有`split_manifest.csv`：fit5957、val1543、test2500。**本次不另生成10%fold0，也不因验证结果不理想重挑划分。

- 核对每类、B/T和信号密度分布，作为评估解释依据；20%本身不等于已经模拟test分布。文件缺失/读取失败必须修复，不得静默跳过或重新划分。
- json相同不是IQ重复；分组是防布局相关泄漏的保守做法，不声称已排除全部波形近重复。
- 所有细片/粗图继承源样本split。归一化只拟合fit。test封存，不参与本计划调参和checkpoint选择。

### 第一场训练采样

每个fit源样本每epoch贡献**1张coarse＋1张fine**，两种视图同等loss权重；fine包括空片。fine索引采用每源确定性随机排列并逐epoch轮转，保证最多34个epoch遍历一遍所有频率片。记录seed、epoch和源ID；persistent worker也必须收到新epoch，不能永远抽同一片。

Dataset一次计算原生谱后返回这一对视图。collate将源样本对展平成同形网络batch，例如2个源样本得到4张`[1,2048,512]`。一次实验C固定为1。

验证则对每个源样本运行**全部fine＋coarse**。训练只抽一张fine是控制成本和细/粗比例的采样定义，不代表推理只看一片；epoch含义及总视图次数需记录。

### 标签

- fine对每个原GT与窗口取正面积交集，再平移为局部框；保留class、instance_id、原框、截断标记。不按面积比例、像素宽度或贴边删除正面积标签。
- coarse映射所有完整GT；同框实例仍各自独立。零面积相交不生成该片标签，原始GT不受影响。
- 绕过默认YOLO图片标签验证/缓存中的`np.unique`去重及最小尺寸过滤。合成两条同类同框GT，经Dataset→collate→评测转换后仍须为两条。
- 不设置同框ignore/crowd，不擅自合并同框类。标准分配器仍可能无法给每个同框实例分配独立正样本，这是baseline限制，应记录而非删GT。

## 5. SAHI、模型和适配代码的职责

| 组件 | OpenCode需完成 |
| --- | --- |
| IQ/STFT模块 | 读取规范、精确512列、功率/粗图、数值协议和缓存 |
| SignalDataset/collate | 源样本对采样、标签、同形batch与坐标元数据；不走OpenCV/RGB文件入口 |

| SAHI tensor adapter | 直接调用核心模型；不做RGB转换、通道翻转、除255或imgsz缩放；提供ObjectPrediction及shift元数据 |
| 合并模块 | fine平移、coarse缩放反变换、边界片段标记、显式class-wise NMS |

在train、训练期val、独立val、回载best、SAHI推理入口挂shape检查。允许模型构造时内部小dummy用于stride推断，但真实数据及资源测试必须是`[n,1,2048,512]`。

模型按配置重新构造C1、nc14、reg_max1、end2end=False。分类数和loss超参数必须正确初始化。使用未融合的YOLO11s预训练权重，按名称/形状迁移主体：首层C1明确检查为RGB核求和；类别输出和不匹配的回归分支按新模型初始化。保存迁移清单，不只记录“Transferred”总数。R1时日志第三项应标L1，不误称DFL；沿用所锁版本该分支的配套loss，不只改输出通道。

默认SAHI额外全图预测关闭，coarse由本项目的功率聚合提供。关闭自动切片猜测、NMM/IoS及低阈值自动切换合并策略；第一版固定下节语义。若版本接口不同，可适配接口，不得改变算法而不记录。

## 6. 完整样本后处理与评测

### 预测与合并的第一版固定规则

1. 核心输出保留多标签类别候选，置信阈值0.001；每视图分数top1000，记录截断次数。此时不使用默认高层图片入口的隐式预处理。
2. fine预测先裁至视图边界、标记片段：若框距**内部频率切片边界**≤16原生格，记为边界候选，单独保存而不作为完整事件输出；原始整段频率外边界不按此规则排除。该规则不用GT，不能用于删除训练标签。粗图不应用内部切片边界规则。
3. fine用`shift=[0,j0]`回到全局[F,512]，coarse先将y乘F/2048。SAHI平移不能代替coarse缩放反变换；不拼接框union、不外推残框。
4. 原样本全局候选按分数最多30000，随后**逐类别独立IoU NMS，阈值0.5**，最终全局最多100个结果。记录各阶段数量。
5. 全局y可能到56000，不能直接套固定max_wh=7680的类别偏移。使用经过大坐标测试的SAHI class-aware实现或逐类torchvision NMS；输出语义必须一致。
6. 同类真实同框可能被NMS压成一个，跨类同框应独立保留。原GT均不删除。预测合并不等于标签去重。
7. 映回真实频率/时间，裁回原B/T。保留源ID、view、片起点、原始候选、边界标记和合并去向，便于定位误差。

### 指标

主指标：**完整原始样本上的strict class-aware mAP@0.5**。辅助AP@0.3、AP@0.7、逐类、B/T及信号密度分层；另将同一批最终预测去类别后算定位AP。采用COCO式101点插值与maxDets=100，GT按instance_id独立、一对一匹配。不得用裁片AP选择best，不给模糊同框设ignore。

另报边界过滤/最终NMS前的proposal recall@1000、IoU=0.5，一对一匹配，作为结构限制诊断；不能代替最终AP，也不能把差值全部归因于NMS。记录无正样本分配的GT数量/尺度，先报告，不自动改变标签或加P2层。

在项目独立环境安装并锁定Ultralytics/SAHI，优先测试本地核查过的Ultralytics8.4.155及所需SAHI接口；保存依赖版本与安装日志。保留现有Torch2.8/CUDA12.8、Torchvision0.23组合，不因本地用了Torch2.14而升级。若版本不支持相同构造/loss，核查后在独立环境适配并复测，不修改共享环境。安装完成不等于DirectReg生效，必须做后续真实验收。

**通过条件：**读取规范有来源；实际N一致；split及GT保留检查通过；明确的C1/R1模型配置、依赖锁和原始数据hash清单已保存。若IQ规范无法确认，给出具体缺失字段，停止在该门槛，不猜读后训练。

### 阶段1：小规模端到端与坐标

覆盖6种B和最短/最长T的真实样本；STFT均为[F,512]；细片均2048×512、coarse同形。验证空片、小正面积框、跨三片宽框、同类/跨类同框，以及t=0/T、整频宽框的坐标往返。先FP32、batch=1、workers=0。

**通过条件：**无隐藏resize/重复归一化；GT行数不丢；细/粗框可正确回映，内部边界候选规则可追踪；全局NMS不跨类错误压框；重新载入模型后仍保持C1/R1及固定输入。

### 阶段2：真实形状的loss、AMP和资源检查

先做FP32 forward/loss/backward，检查完整高框及普通框有可用回归梯度；再测试本任务AMP的forward、loss和有限梯度。默认RGB AMP探针通过不能替代此验收。

显存用真实训练步（含优化器状态）测microbatch=1/2/4/8，先固定值，不用按方形估算的auto-batch。选择峰值reserved显存≤20GiB的最大可用值；成对视图优先偶数batch，必要时一对顺序microbatch1累积。首选AMP；若不稳定先退FP32、小batch，不压缩频率轴、不缩backbone。

再测workers=2/4/8与缓存策略，报告STFT、等待、传输、前向/反向、合并耗时及CPU/RAM/GPU峰值。不能仅测输入张量大小代替训练显存，不能把缓存热读当冷读。

基于冻结的split清单精确统计：每训练epoch为`5957×2=11914`张视图，50轮为595700张；每次完整val视图数为`sum(n_fine(sample)+1)`，不能只套平均片数。测速须包含读取/STFT、全部fine/coarse、坐标和后处理、指标计算，给出首场50轮及完整验证的预计耗时。

验证默认每5轮。若实测预计验证时间超过整个运行总时间的1/3，可在正式训练前固定为每10轮＋最后一轮，并记录理由；之后不按AP高低改变频率。第50轮已经完整验证时不重复再跑同轮。无真实验证的epoch不能用历史fitness更新best。该成本核对属于阶段2，不另要求一轮泛泛审批。

### 阶段3：16源样本过拟合检查

只从fit选16源样本，覆盖类别和B/T，尽量无近同框歧义；不修改这些样本的GT。使用相同两视图训练和完整样本推理，最多2000次优化器更新。目标为子集mAP@0.5≥0.8、loss下降、图中边界与类别合理。

未达到时先排查读取、尺度、归一化、头/loss、标签和映射，不自动跑长训练或删难例。极窄框分配限制可单独诊断；不能只靠loss下降宣告过关。修复后重新验收。

### 阶段4：首场正式训练

阶段0–3通过后执行，无需再提交泛泛选型建议。固定配置：

| 项目 | 值 |
| --- | --- |
| baseline ID | yolo11s_c1_directreg_2048x512 |
| epochs | 50；第一场不做提前停止，确保覆盖最大34片的轮转 |
| optimizer | AdamW，lr0=0.001，weight_decay=0.0005 |
| schedule | cosine，末端lr比例0.01，warmup3 epoch |
| loss权重 | 沿用所锁版本默认；如为box7.5/cls0.5/第三项1.5，R1时第三项为L1，记录映射 |
| 有效batch | 目标16张视图，物理batch按阶段2实测，梯度累积补足 |
| 精度 | 本任务验收通过的AMP；否则FP32并记录 |
| seed | 1729 |
| 验证 | 对固定1543个val源样本跑全部fine＋coarse；默认每5轮，阶段2可按成本规则预先固定为每10轮；第50轮不重复验证 |
| best | 以完整样本strict mAP@0.5选择；保存best、last、配置、split/normalizer hash |

SignalValidator应显式返回`fitness=完整源样本mAP@0.5`，并验证Trainer确实据此保存best；不能继续使用默认COCO综合fitness而只在报告中声称按AP50选择。

训练中遇到非有限loss、shape/GT计数违规、磁盘低于安全余量，停止该运行并保存诊断；修复后按一致配置恢复，不静默改变数据/尺寸/标签策略。不得未经验证启用梯度检查点；也不以减少推理覆盖片数代替显存优化。

### 阶段5：交付首场结果

回载best，使用独立验证入口复核固定尺寸和原始样本级指标；交付逐类及B/T表、完整预测、典型错误、同框/NMS限制、速度/显存/CPU/缓存命中率和配置。test继续封存；本计划不在test上选参数。
