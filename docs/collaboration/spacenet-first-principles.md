### 2.1 为什么是 300 个 query

一个 query 是**一个可能的信号实例**，带一个框和 14 个类别分数。一个文件可以有多个同类信号。训练中未匹配 query 的分类目标是 14 类全零，背景没有一个独立的第 15 个输出分数。在本地训练几何复算中粗图最多 8 个标注、细片最多 7 个相交标签，300 源自 D-FINE 通用视觉配置。它没有由本任务的标注密度推导过。第一批候选保留较多可能帮助弱信号，过多则增加自注意力、匹配、排序和重复输出成本。 [D-FINE 论文](https://arxiv.org/abs/2410.13842) · [上游 Q 配置](https://github.com/Peterande/D-FINE/blob/956d170/configs/dfine/include/dfine_hgnetv2.yml#L36-L68) · [查询选择](https://github.com/Peterande/D-FINE/blob/956d170/src/zoo/dfine/dfine_decoder.py#L694-L749) · [背景目标](https://github.com/Peterande/D-FINE/blob/956d170/src/zoo/dfine/dfine_criterion.py#L80-L106)

`Q=300` 经过解码得到 4,200 个框/类组合分数。另一个参数 `K=300` 取组合中的前 300，同一个框可以带多个标签。分类消融已经证明全局硬取每框一个类会损失约 6.82 个百分点。原 FM 诊断称 80/88 个漏检发生在 `no_raw_candidate`，逐行看实现，所谓 raw 是 **K=300 和分数门槛之后**。排在第 300 名以后的框和类别组合此前都未追踪。 **先固定 Q，消融输出 K。** 真要加速 Q，另做同权重 Q=75/150/300 的真实前向，加等预算重训对照。decoder 的自注意力使缓存里删 query 和减 Q 的前向含义不同。当前优先追精度。 [原阶段统计代码](https://github.com/2783264321-arch/My_experience/blob/4cbdd5f/scripts/dfine_query_ablation.py#L55-L78) · [上游 top-k](https://github.com/Peterande/D-FINE/blob/956d170/src/zoo/dfine/postprocessor.py#L35-L59)

### 2.2 C1 为什么已经用到了三个 RGB 核

本项目首层是 `W1=WR+WG+WB`，对同样归一化的功率图 P，有 `conv([P,P,P], [WR,WG,WB])=conv(P,W1)`。偏置、padding、后续层相同，重参数化在实数运算中等价。本地随机张量 `1×1×2048×512`、32 个输出核、stride 2/pad 1 复核，FP32 相对 RMS 误差约 1.1e−7，BF16 约 0.30%，是此合成条件下的有限精度结果。直接复制功率没有增加信号证据，不占一场正式训练。三个真正不同的通道可以用长窗功率、短窗能量变化及归一化高阶统计，也可以在有物理含义的分支融合。复通道中相位或实虚部对频偏、起始相位与混叠很敏感，上一轮的 C3 不能外推到所有物理表示。 [迁移初始化](https://github.com/2783264321-arch/My_experience/blob/4cbdd5f/scripts/detector_upgrade/adapters.py#L80-L117)

## 3. 功率究竟能识别什么

### SRRC

对 `s(t)=Σ a[k] p(t−kT)`，在独立零均值符号、相同符号率、同一 SRRC 成形脉冲、等平均符号功率条件下，时间平均 PSD 与 `E|a|² |P(f)|²/T` 成正比。理想 QPSK 与归一化 16QAM 因此可以有相同 PSD。正确恢复到符号采样点后，两者的归一化四阶幅度矩 `E|a|⁴/(E|a|²)²` 分别是 1 和 1.32。有限窗能量方差、幅度分布和跨时刻变化也能携带区别。它们容易被窗口平均、量化、频偏和叠加削弱。某些完整重叠 STFT 的幅度在数学上可相位恢复，相关条件不覆盖我们按格平均、裁动态范围之后的 C1。 [STFT 相位恢复条件](https://arxiv.org/abs/1508.02820)

对独立零均值复信号，未归一化高阶累积量在同频叠加时相加，高斯噪声理论四阶累积量为零。归一化时除以总功率的平方，等功率两信源且忽略噪声时，目标的四阶贡献被压到单源的约四分之一。已知目标中心并低通可以去带外干扰。同频共存时，仍需要定时、载波结构、信道或多观测中可利用的差异。

### Wi-Fi

在相同子载波占用、平均符号功率和发射结构下，QPSK、16QAM、64QAM 的平均功率谱在理论上可以相同。OFDM 时域是多个子载波相加，单子载波调制差异变弱。恢复符号并按子载波做 FFT 后，归一化的符号四阶矩分别约 1、1.32、1.381，理想上保留幅度差异，真实数据还要考虑导频、信道、前导和频偏残差。已提交的 SpaceNet 训练 IQ 诊断在一部分信号看到的是 legacy-like 3.2 μs 有用段和 0.8 μs 前缀。0.7 ms 积分约 175 个这样的周期，不能用 WiFi6 标签替代逐候选的参数验证。原有 GT 框诊断中，同步可用率在干净组约 67%、重叠组约 18.2%、总体约 23.9%。同步成功的样本有高阶统计可分性，回退后的总体增益受覆盖率约束。 [INFOCOM 2024 OFDM 调制识别](https://arxiv.org/abs/2403.19292) · [项目训练 IQ 前端](https://github.com/2783264321-arch/My_experience/blob/4cbdd5f/reports/baseline3_wifi_expert/frontend_validation.md) · [真实留出比较](https://github.com/2783264321-arch/My_experience/blob/4cbdd5f/reports/baseline3_wifi_expert/wifi_expert_comparison.md)

SpaceNet 的实采混合与合成来源是应利用的研究信息。优先在 fit 检查原始来源字段、增益和噪声底、相同标注模板、同文件/同信源间是否相关。实采与仿真标签比例来自说明，当前缺逐来源可验证清单，先把可用的采样尺度、框重叠、原频点和信号类型当作分层量。20/40 MHz 带宽可用于限制宽带组的竞争，组内调制交给真实波形证据。规则要对框边界误差、剪裁缺带和来自同频其他信号错同步建模。全时频框相交只表明空间重叠，不能当成实测 SIR。

### 3.1 本地合成实验

生成 20 MS/s、10 MHz 带宽 SRRC，2 ms 波形，名义 12 dB SNR。两类符号随机生成。每对匹配增益、相位、定时、频偏、AWGN 和同频干扰，两类的目标符号独立。每个干扰条件 320 条训练、320 条独立合成留出，四种表示都用标准化逻辑回归，固定合成随机种子。长窗功率使用 0.7 ms Hann 与同样的 2048 频段均值和 log 裁幅。使用合成目标时间区域内的帧。相同波形分别取功率、包络和理想同步后的特征。

| 表示 | 无同频干扰，平衡准确率 | 0 dB 同频干扰，平衡准确率 |
| --- | ---: | ---: |
| 仅平均粗功率谱 | 47.81% | 48.44% |
| 粗图时变能量和纹理统计 | 86.56% | 54.06% |
| 接收混合 IQ 的包络高阶统计 | 100.00% | 75.94% |

## 4. 面向 SOTA 的执行顺序

### 第一项交付。一次完整 val，分清评分、分类与几何的空间

用 e25 原权重只前向一次。每个原始 view 保持完整几何，比较全 query、原 K=300 分数筛选、边界/类别过滤、合并后四阶段。在相同输出上测 K=100/300/600。除实际 AP 外，给出 0.5/0.75/0.90/0.95 下原始几何的一对一最大匹配数和逐类覆盖。在 K300 的 *最终* 候选上做一次诊断性重标，将一对一匹配候选标为 GT 真类，保持框和原分数、其余候选不动。它衡量按这个具体操作能找回多少分类 AP，包含排序限制。最大匹配给出固定候选的覆盖容量。两者都不是数据集的理论上限。全程使用同一阈值、IoU、合并上限、BF16 batch 8。报告 Wi-Fi20、Wi-Fi40、SRRC 与 FM，并分开写真实规则与真值诊断。

已有脚本 `python scripts/audit_dfine_candidate_budget.py --output reports/detector_upgrade/dfine_candidate_budget_val.json` 用现有正式验证入口的构图、解码、合并和指标。首要核对 K300 是否复现 e25 的 0.761728 / 0.713928。脚本只读 val。若 FM 回收主要发生在原始候选已存在、K300 丢弃，则候选预算优化与分类改造可以分开推进。若全 Q 也缺覆盖，才优先做 FM 的细片、短窗口边界和完整可见目标监督。再次盲目放宽全局 100 或 classwise NMS 会混入排序变量。

### 主研究实验。给检测器新增真正不同的调制证据

一个可实现的版本是 **全频/细片定位＋预测框局部 IQ 读出＋调制分数残差**。D-FINE 给时频框和每类分数。用预测框中心做复数下变频，带宽和边界留可验证余量，低通并抗混叠降采样。对同一份局部波形同步产出三类物理量。

| 输入 | 为什么有用 | 具体可控的实验 |
| --- | --- | --- |
| 长窗功率及短窗功率变化 | 让模型看到同一 ROI 的谱形、边界及更快的能量变化 | 固定 0.7 ms 基础输入，局部短窗比较物理窗秒数，聚合成少量一致帧。标签前沿用同样预处理 |
| SRRC 局部归一化幅度分布及复数序列 | 对恒幅或非恒幅符号的采样二、四阶统计敏感 | 基线输出接收包络分位数、高阶矩和短 I/Q embedding。匹配滤波常数不确定时保留两种短时观测，不用同步失败淘汰整个候选 |
| Wi-Fi 候选级短 FFT 子载波证据 | 载波频率对齐后更容易直接比较 QPSK、QAM 的幅度/相位结构 | 至少用 legacy-like CP 作起点，候选内用类无关 CP/谱结构搜索，估偏、FFT、剔除导频/无效载波后跨符号合成矩和直方图。以一致性和信号质量作特征，主要由训练学会何时采信 |

这一步不把 Wi-Fi/SRRC 作为额外独立的整套模型。轻量分支读取相同的 D-FINE query 和候选，输出各组内 logit 残差，初始残差为零。以已有基线的分数作为退路，让模型学证据的可靠度。匹配候选较难区分时可保留多个类别分数进入原合并。建议可微的检测打分融合和适度的监督，允许 roi 提取用分离的信号处理算子离线缓存。训练样本来自 fit 中图像级分组、同一检测器的预测框，优先采用 fit 内样本外预测或冻结检测器后受控的局部框扰动，保留未匹配/可疑重叠候选作为保持基准分数的证据，验证用真实预测框。输入组别路由由预测得出，以物理带宽和置信度作软条件，禁止拿真类或真值框定义验证分支。若同信道含多条候选，要看 CP 锁的是哪条，混合的 IQ 不应被当作单轨纯净星座。

消融做成三列同一张完整 val 表。**A 原 D-FINE。B 相同的新分支只看局部 C1。C 新分支看 C1＋局部物理量。** B/C 匹配候选与预算一致，B 的追加输入维度可填固定零以对齐参数量，单独报告具有有效波形证据、同步失败、按标注可估的重叠组。先判明 C 是否优于 B 并提高系统 AP，再决定解冻后部特征联合训练。结果按每文件配对再汇总，包含 14 类 AP、Wi-Fi 两组、SRRC、FM、严格 mAP、覆盖和实际延迟。短训结果应直接回系统 AP 表，争取避免纯局部准确率的二次误导。

### 工程侧并行但独立的训练消融

保留 C1、e25 初始化、view 顺序和每轮有效 batch，给原损失与细片不可用 Wi-Fi 匹配项的分类忽略分别用同等小预算，例如 5 轮。只改 matched query 的分类权重，保持原匹配与框回归。逐层确认最终分类、decoder aux、encoder aux、denoising 的目标索引，忽略的范围在两个 arm 的汇总中记录。依据固定 val 的粗图 Wi-Fi、细片窄带和总 AP 决定是否延长。

如训练可接受的视图覆盖确实限制个别类别，再考虑预算中性的采样，对 `1 粗＋1 细` 中细片换成「均匀轮转＋完整目标高频抽样」的混合概率，留足空片作为真实困难负样本。评估显式使用片边余量和完整频宽。这个实验与分类忽略分开。50 轮训练后半段 e50 在类无关 AP75 提升同时总体 AP 降低，需要把分类排序的早停与学习率选择纳入每 5 轮报告。只有方案可复现的改动才做两个独立 seed 的全预算复验。

多分辨率/LS-STFT 是可比的前端支线。复现者应公布单调频率映射和逐框逆映射、保持绝对 MHz 坐标评分、使用相同的物理功率归一，匹配预算对照。ZoomSpec 在一个 1 MHz 局部周期内重分配线性 STFT 频轴采样密度，能改变像素占格与网络学习几何。它不凭重采样产生原来没有的子载波调制信息。局部短窗的物理变化与非线性插值要分开做。 [ZoomSpec 原文](https://arxiv.org/html/2604.13568v1#S3.SS1)

## 5. 公开成绩如何追

- **目标取严格 mAP。** ZoomSpec arXiv v1 表 III 报告官方 test 严格 mAP 78.1，D-FINE 普通/LS-STFT 对照 60.6/74.3。与已归档 D-FINE-L 68.21 的名义差 9.89 个百分点。640×640 只是网络栅格，论文还有非线性频轴、预测框局部 IQ、时域细化和连续坐标回归。两套成绩能否横比，取决于数据版本和评测协议。 [论文表 III](https://arxiv.org/html/2604.13568v1#S4.T3)
- **150/200 ms 是发布资料已有的不一致。** SpaceNet Version 1.1 的 Advanced 测试集说明第 8 页写 20–150 ms，同页时长枚举却列到 200 ms。茶思屋发布页也给出相同的两种写法。该 PDF 第 9 页及发布页的测试统计均列 20/40/60/80/100/150 ms 六档，频数为 407/385/433/437/426/412，合计 2,500。项目导出主表按复 IQ 点数与观测带宽逐行复算，六档计数完全吻合。ZoomSpec 表 I 的 200 ms 确实在 Test 的时长行，正文写明采用官方 train/test 划分。应把该数字记录为与官方档位枚举一致的文档差异，现有证据不足以据此判定用了不同的测试数据。 [茶思屋 Advanced 发布页](https://www.chaspark.com/#/s/SpaceNet?multi=zh) · [ZoomSpec §IV-A 表 I](https://arxiv.org/html/2604.13568v1#S4.T1)
- **任务和分数各按自己的来源记录。** Advanced 的任务是从宽带复 IQ 中找出多个信号的时频边界及 14 类标签。公开划分为 7,500 train / 2,500 test，项目的 5,957 fit / 1,543 val 来自公开 train。两份官方介绍给出数据定义和划分。论文横比时还须核对样本和标签修订、是否逐图全局前 100、逐类 maxDet、是否类别无关及 IoU 阈值。Li 等窄带工作的 69.5 来自官方训练部分中 50 MS/s 子集的 7:1:2 划分，标签有局部修正。EMSpec-Instruct 表 S4/S12 涉及 11 类 SpaceNet 与仿真扩展，72.19 是类无关严格 AP。 [茶思屋 Advanced 发布页](https://www.chaspark.com/#/s/SpaceNet?multi=zh) · [Li 等](https://doi.org/10.1016/j.phycom.2026.103432) · [EMSpec-Instruct](https://arxiv.org/html/2610.12142v1)
- **自己有一套别人能重跑的账。** 现有项目指标是 101 点插值、分图一对一，输出前 100 在项目合并阶段固定。用冻结 val 预测导出到官方评分器核算差异。最终模型、评测设置和预测上限冻结后再正式评 test，公开代码版本、划分哈希、模型权重或可复现指令、原报告与独立重复的逐类结果。仅从现有 AP 或同框比例推出不可突破的数据上限没有依据，源波形不可辨识与模型表达不足也需要分开的实验。 [项目评分实现](https://github.com/2783264321-arch/My_experience/blob/4cbdd5f/src/signals/metrics.py)

### 6.2 下一轮执行口径

**本轮只回答一件事。固定同一个检测器的候选，增加局部物理特征能否比局部功率图带来更好的系统 AP？** Wi-Fi 20/40 MHz 是重点，SRRC 作为同一轮的第二类调制证据。复用已有前端和局部 IQ 代码，比较 A/B/C 一张表。

- **冻结候选与坐标。** 使用 e25 的 C1 粗细视图、BF16 batch 8、K300。取按现有边界与细片类别规则过滤后、进入全局合并前的候选。按样本和视图中的 query 标识缓存框、现有类别、原分数和裁剪坐标。A 用原分数走现有入口，复现 `0.761728 / 0.713928`。B/C 使用同一个候选池和同一套训练预算，零残差路径应回到 A。若现有审计只存了聚合 JSON，按正常入口重建一次候选缓存，供两组复用。
- **B/C 只差局部物理输入。** B 读预测框内的局部 C1 功率图，C 在相同局部 C1 和相同候选元数据上增加短时功率变化、SRRC 包络/高阶矩、Wi-Fi 候选短 FFT 子载波统计和可靠度。B/C 裁同一段真实 IQ，按现有 STFT hop 和像素中心约定还原时间，按观测频率还原中心和带宽。复用现有下变频、带限/抗混叠降采样与 CP/CFO 检查。同步失败也进入完整评估，信号证据缺测时按预先锁定的回退方式处理。
- **训练用真值做标注，推理按预测候选路由。** 在 `fit` 内按原 IQ 文件或已有分组划分训练与校准。几何匹配用于标注训练候选，保留未匹配、跨组及歧义框，也要让分支学会保留原分。推理候选的组别和计算预算只看基线类别分数、预测带宽、视图及 IQ 质量。训练按 `0–2`、`3–5`、`10/11` 分组。SRRC 需要报告各带宽覆盖，把已验证的 10 MHz 证据与其他带宽区分。强度、质量门控与检查点都在 `fit` 内锁定。
- **让目标类别分数可以变。** B/C 给原有候选的组内分类分数加残差，保留同一 query 的多类候选。框坐标和候选身份固定，原分数用于 A。B/C 的类别排序随新分数变化，并分别走原来的类内 NMS 与每文件前 100，最终入选的候选因此可以不同。把这个入口讲清楚，验证时用所有可路由预测，不用真值挑干净框或已匹配框。
- **按完整 `val` 决定。** 给 A/B/C 报 14 类 mAP50、严格 mAP、三组 AP、候选覆盖、错类修复与新错类、未匹配改动和额外耗时。用 `C−B` 评估物理输入，`C−A` 评估整条改动，`B−A` 解释局部功率本身的作用。若局部正确率提高但整体严格 mAP 未获得可复核净收益，就收尾本版；若 B 已得到同等收益，优先保留较简单的分支。首次交付是一张端到端 AP 表，采用现有前端完成一次对照。
