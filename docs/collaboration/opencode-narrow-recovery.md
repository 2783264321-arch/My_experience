## 假设

同一次 0.7 ms STFT 里，粗图的面积加权平均丢掉了两类带内信息：

1. **带内峰值**（PAPR）：窄带信号在原生频率格上是一个尖峰，平均后
   被摊平；粗图可能因此漏检，细片能找到。
2. **能量质心**：平均后的行没有频率偏移信息；如果窄带信号不在粗行
   中心，粗图无法区分。

问题：这些被丢掉的信息能否解释或补到「粗图漏掉、细片找到」的窄带实例，
让粗图以低成本找回一部分切片收益（不加输入通道，只加统计量）？

## 方法（只读）

- 复用冻结的 B（仅粗图）与 C（全视图）完整 val 预测。
- 逐个窄带类（9/12/13）GT 实例：
  - `c_only`：C 匹配、B 漏掉 —— 核心目标组；
  - `both`：两者都找到；
  - `b_only` / `neither`：对照。
- 每个实例在**同一份原生 0.7 ms STFT** 的 GT 频带 × GT 时段内计算：
  - `mean`（= 现在粗图给模型看的量）、`peak`、`PAPR = peak/mean`、
    `centroid_offset`（能量质心相对带中心的偏移，按半带宽归一）。
- 对照组：
  - **背景带**：同 B/T 样本中无 GT 的空频带（噪声基线）；
  - **B 的窄带误检框**（无窄带 GT 重叠）。
- 全部 1,543 个 val 样本逐样本重算 STFT（CPU，约 8–10 min）。

## 待回答

1. `c_only` 的 PAPR / peak 是否显著高于背景和 B 的误检框？如果只是
   频点数或噪声效应，PAPR 会随 B（频点数）漂移而背景同样高。
2. `c_only` 的 |centroid_offset| 是否比 `both` 更大？质心是否提供了
   有用的频率偏移，而不是 0 附近的噪声。
3. 分 B/T 检查这些量是否稳定（排除"某个带宽特高"的假象）。
4. 若 (1)(2) 成立：值得做一轮配对训练（粗图 + 两个低成本统计通道：
   带内 PAPR、带内质心偏移，不加 STFT 复数通道）。
   若不成立：说明被平均丢掉的信息不可恢复或不可用，直接关闭该假设。

## 结论

1. **peak 是主要可恢复信息，PAPR 不是。**
   - `c_only` 的带内**绝对峰值**与同 B/T 背景（AUC 0.995）和 B 自己的
     窄带误检框（AUC 0.965）几乎完全可分。
   - PAPR 只有中等分离（0.704），且在 80 MHz 失效（0.502）——
     背景在那里也有大峰均比，说明 PAPR 确实部分是**频点数/噪声效应**。
   - class 12 是 PAPR 反例：c_only 的 PAPR（10.6）甚至低于 both（40.2），
     但 peak AUC 仍 0.983。
2. **centroid 是真实但较弱的第二信号。**
   - `c_only` 的 |centroid| 中位 0.057，高于 both 0.010、背景 0.012。
   - 分 B 的 AUC 0.62–0.84，80 MHz 处最弱（0.618）。
   - 它提供的是**频率偏移**信息：粗图漏掉的窄带实例更常偏离能量
     质心/行中心，不是纯噪声。
3. **80 MHz 是收益最大的地方，也是 PAPR 最不可用的地方。**
   - 542 个 c_only 中 165 个（30%）在 80 MHz，粗图窄带召回最低。
   - 在 80 MHz，PAPR 与背景不可分（0.502），centroid 也降到 0.618；
     真正可恢复的是绝对 peak（vs 背景 0.995、vs 误检 0.964）。
4. **局限**
   - 只读：只能证明信息在**同一份 STFT**里存在，不能证明检测器能利用
     它或能转成 AP。
   - `c_only` 由当前 C 推理匹配定义，部分实例可能因排序/置信而非可见性
     被粗图漏掉。
   - 背景带是固定宽度条带，不是逐实例带宽匹配；这是保守对照。
   - AUC 是排序指标，没有阈值/误检预算。

## 建议

**值得做一轮配对训练，但只做最窄范围，不加复数/短窗通道。**

从同一份 0.7 ms STFT 派生两个 `2048×512` 低成本通道：

1. `band_peak`：每个粗行/时间列，其原生频率支撑内的最大功率
   （或 log 后），替代被面积平均完全抹掉的峰值。
2. `band_centroid`：每个粗行/时间列，能量加权频率偏移（相对行中心，
   归一），0 = 行中心。

**不要加 PAPR 通道**：它与 peak 信息高度重叠，且更受噪声/频点数影响。
**不要加 dense/短窗/复数通道**：稠密 C3 已在 4315026 收尾。

配对训练口径：
- 与 C1 同一 1536/384 子集、同一 20k 步、同 seed、同初始化；
- 通道 0 = 原版功率（逐元素一致），通道 1 = band_peak，通道 2 =
  band_centroid；
- **预注册 checkpoint 规则：只用 last**（不要再用 384 子集 best 挑权重，
  已证明不稳定）；
- 报告窄带 9/12/13 AP、粗图漏掉 c_only 实例的找回数、0–5 宽类不劣化、
  以及 B=80 MHz 单列核对；
- 如果不能找回有意义的 c_only 子集或损害宽类，就关闭该假设。
