# Wi‑Fi 同步失败诊断 · 独立审查

2026-11-21。冻结 YOLO、W‑Shared 专家和现行同步/路由规则。
SRRC 已在 `1b75b47` 收尾，本轮不重开。只使用 adaptation-train /
calibration-dev；**final-dev 保留集与 test 不动**。不重训、不改推理。

## 1. 要验证什么

共享专家在完整 val 上约 +1 pp mAP，但只有 807/4,844 个 Wi‑Fi
预测框可用。GT 框与 Pred 框同步率只差 0.28 pp；40 MHz 的
class4/5 即使 GT 框同步率也远低于 class3。问题是：

- 失败是**整个框内都没有可靠 CP 结构**，还是**长片段中只有一部分**
  被交叠/突发间隔/边缘干扰拖累？
- 短段检查能否找回可用符号，且固定专家在找回样本上**净改对**
  是否为正？
- 短段是否会把框内**另一条信号**当成目标？

## 2. 已有证据

- 全量 val：Wi‑Fi 预测 4,844，同步成功 807（16.7%）。
- 配对 1,394：GT 同步 17.93% vs Pred 17.65%，差 0.28 pp。
- class3 31.6% vs class4 11.2% / class5 9.1%（GT 框亦如此）。
- clean 52.1% vs any-overlap 14.7%（GT 框），overlap 是主导因素。
- 现有整段检查：框中心最多 20 ms，bandlimit 后全段 CP 扫描，
  metric>0.34 且 ratio>15 才通过。

## 3. 主要风险

### R1. 短段的多重比较/选择偏差

长框切多个短段，总会有一个段“看起来更好”；必须固定段长/跳步/
段数，使用同一门限，并按 label-blind 规则选段（最高 metric），
不能按真实类别选。

### R2. 把另一条信号当成目标

框内可能有别的 Wi‑Fi/非 Wi‑Fi 信号。短段越短，越容易只覆盖
另一条信号。必须报告短段与框内其他标注信号的重叠比例，以及
专家预测是否恰好等于另一条信号的类别；这只是风险证据，不能
证明捕获。

### R3. 通过率不等于收益

短段可能找回很多符号，但专家在找回样本上净改对为负，或只改
低分/未匹配框。必须报告：
- 新找回符号/块数；
- 固定专家相对 YOLO 回退的改对/改错/净改对；
- 按 class3 / class4 / class5、按 overlap 分层；
- 未匹配候选只报告改动与风险，不伪造标签。

### R4. 短段符号少，专家方差大

2 ms 段在 40 MHz 下约 500 个 3.2 µs 符号，最多 4 个 128-symbol
block；专家预测方差比整段大。必须用固定 3 seeds 平均 softmax，
并报告每段 block 数。

### R5. 不能改规则

本轮只诊断；短段通过不能直接替换现行整段规则。若净收益为负或
风险高，应保留现行规则并收尾。

## 4. 预注册方案

- 数据：adaptation-train + calibration-dev 中，class4/5 的
  **Pred 框整段失败**配对全部纳入；class3 的 Pred 框失败配对作
  对照；另抽 12 个 Pred 框整段失败、未匹配到 Wi‑Fi GT 的
  class4/5 候选。
- 段：在现行整段检查的**同一中心 20 ms 窗口**内，切 **2 ms**
  段，跳步 1 ms；长窗最多 20 段，均匀取起点；不足 2 ms 用整段。
- 门限：与现行完全相同（metric>0.34、ratio>15），不因类别调。
- 选段：通过的段中取 metric 最高者做专家输入；所有通过段的
  n_kept/blocks 计入“新找回符号”。
- 专家：W‑Shared 3 seeds 固定权重，块平均 softmax，再 seed 平均；
  按预测家族映射 3→6 类。
- 计分：在匹配样本上与 GT 比较；`corrected = expert对 & YOLO错`，
  `broken = expert错 & YOLO对`；报告净改对、准确率、混淆。
- 其他信号风险：计算选段与框内其他标注信号的面积重叠；
  `other_frac>=0.5` 记为高重叠；若专家类别等于另一条信号类别，
  记 `expert_matches_other`（仅风险证据）。
- 未匹配：只报告找回数、专家改类数、高重叠数；不计正确/错误。
- 不重训、不改推理、不使用 final-dev/test。

## 5. 更省算力的做法

1. 只跑 class4/5 的失败配对（约 215 个）+ class3 对照（约 83 个），
   不碰全量 1,543。
2. 2 ms 段、最多 20 段/框；只对通过段跑专家。
3. 先看匹配集净改对；若 ≤0，不扩展未匹配/其他段长。
4. 不训练新分类器；固定专家 3 seeds 即可。

## 6. 结论会怎样改变

| 观察 | 结论 |
| --- | --- |
| 短段找回多、净改对 >0、其他信号风险低 | 值得进一步预注册短段规则 |
| 找回多但净改对 ≤0 | 通过率是假象，收尾 |
| 净改对 >0 但高重叠/专家匹配其他信号多 | 可能是捕获其他信号，不能采纳 |
| class3 也大量“新找回” | 失败不是 class4/5 特有，规则需重审 |
| 只找回少量、净收益小 | 整段失败主要是全框无结构，收尾 |

## 7. 边界

- 只诊断，不改 inference/规则/权重。
- 不重训 YOLO/Wi‑Fi 专家；不加相位；SRRC 不重开。
- 结果写回 Baseline-3 共享记录，开头三句话总结。
