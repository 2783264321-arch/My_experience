# SRRC 10/11 局部 IQ 分类 · 结果与独立判断

2026-11-21。只使用 `fit`；**未使用 val/test，未接 YOLO，未重训任何
Wi-Fi/YOLO/专家模型**。GT 框裁剪；所有同步参数/门限 label-blind。
本轮目标是回答：恢复符号后的幅度有没有用？在同一批恢复符号上加
相邻相位差有没有可重复收益？

## 0. 结论先行

1. **幅度信息确实存在，但它不是“恢复符号”独有的。** 在恢复成功
   子集上，未同步 IQ 幅度统计（B0_unsync）已达到 **79.3%**；
   恢复符号幅度（R_amp）为 **80.3%**，只高 **+0.94 pp**
   （CI [−4.2,+6.2]，p=0.86）。去掉未同步幅度特征后，基线掉到
   **59.2%**，说明大部分幅度信息在**未同步**的局部 IQ 统计里
   已经可用。
2. **相邻符号相位差没有可重复收益。** R_amp+phase 比 R_amp 高
   **+1.41 pp**（CI [−1.4,+4.7]，p=0.55）；但小型 MLP 上
   phase 反而低 **−1.1 pp**，且类别方向相反（class10 +3.4 pp、
   class11 −1.1 pp）。不满足“可重复”的预注册判据。
3. **恢复成功率是主瓶颈。** 全局恢复成功 **36.9%**（673/1,824）；
   clean 52.0%、any 32.9%、strong 28.2%。全实例净收益只有
   **+1.28 pp**（R_amp，CI [−0.7,+3.2]）和 **+1.83 pp**
   （R_amp+phase，CI [−0.2,+4.0]），均包含 0。
4. **低交叠且恢复成功的样本分类很好**：clean 子集 B0 93.3% /
   R_amp 95.0% / R_amp+phase 96.7%（n=60）。因此卡点不是
   “clean 样本的特征判别”，而是**恢复覆盖率 + 交叠**；同时
   未同步幅度统计已接近恢复幅度，所以继续加同步/相位特征不划算。

**决策**：保留简单方案；不把相位差列为带回 Wi-Fi 的线索；不扩大
模型。若继续，优先解决恢复/交叠与标签可靠性，而不是更复杂的
分类器。

## 1. 数据与划分

- 数据：fit 10 MHz 档 class10/11，**1,824 实例 / 1,572 文件**。
- 按 `sample_id` 分组、文件级 70/30 分层（class 组成 × strong
  overlap）；seed **20261121**；assignment SHA256
  `c3138145546e13f7889b9b36707960f1b3552be488ca811ed647ba2f2d95c9dc`。
- train：1,278 实例（10:657 / 11:621），1,100 文件；
  holdout：546 实例（10:284 / 11:262），472 文件。
- holdout 交叠：clean 113、any 171、strong 262。
- 未使用 val/test；未用留出集调参。

## 2. 前端与合成验证

- GT 框中心裁 2 ms → `demod_to_center`（零频=观测中心）→
  10.2 MHz 带限 → 两端各 0.5 ms 修剪。
- 固定 SRRC 先验 alpha=0.2/R=8.333 MHz，tone 扫描 0.8–1.1×R；
  由 `|y|²` 符号率线反推 R/alpha，再做一次匹配滤波/定时细化。
- 门限固定：tone strength ≥0.04、peak/median ≥8、coherence ≥0.5；
  不使用真实类别选择参数。
- 合成校验（QPSK/16QAM × alpha 0.2/0.35，50 Msps，CFO 3 kHz，
  20 dB SNR）：全部 `ok`；R 误差 **<1e-5 %**，alpha 误差 ≈0，
  m4 = 1.007/1.321（alpha 0.2）、1.004/1.318（alpha 0.35），
  与 QPSK/16QAM 参考一致。说明匹配滤波/定时实现本身正确。

## 3. 恢复成功率与失败原因

| 分组 | n | ok | 成功率 |
| --- | ---: | ---: | ---: |
| 全部 | 1,824 | 673 | **36.9%** |
| class10 | 941 | 359 | 38.2% |
| class11 | 883 | 314 | 35.6% |
| clean | 383 | 199 | **52.0%** |
| any-overlap | 1,441 | 474 | 32.9% |
| strong ≥25% | 847 | 239 | **28.2%** |

失败原因：`gate_strength` **1,136**、`gate_peak` **15**；没有
`no_tone`。即：符号率线几乎总能找到，但大量框的线强度/峰值不够；
主要瓶颈是**信号/交叠质量与门限**，不是“完全找不到线”。

## 4. 成功子集上的配对比较

holdout 恢复成功 **213** 实例（class10 119 / class11 94）。所有模型
在同一成功子集上训练/评估；B0_success 与 R_amp/R_amp+phase 使用
相同的成功训练实例（460 个）。

| 特征集 | 成功子集准确率 |
| --- | ---: |
| B0_power（局部功率 only） | 58.2% |
| B0_unsync（功率+未同步 IQ 幅度/相位） | **79.3%** |
| B0_no_unsync_amp（去掉未同步幅度） | 59.2% |
| B0_no_unsync_phase（去掉未同步相位） | 78.4% |
| **R_amp（恢复符号幅度）** | **80.3%** |
| **R_amp+phase（幅度+相邻相位差）** | **81.7%** |

### 配对差值

| 比较 | Δ | 95% CI（文件 bootstrap） | 纠正/改错 | McNemar p |
| --- | ---: | --- | ---: | ---: |
| B0_unsync → R_amp | **+0.94 pp** | [−4.25,+6.16] | 17 / 15 | 0.86 |
| R_amp → R_amp+phase | **+1.41 pp** | [−1.44,+4.67] | 7 / 4 | 0.55 |
| B0_power → B0_unsync | **+21.13 pp** | [+13.2,+29.4] | 65 / 20 | 1.0e−6 |
| B0_no_unsync_amp → R_amp | +21.13 pp | [+13.1,+29.5] | 65 / 20 | 1.0e−6 |

**关键**：未同步幅度统计（把 B0_no_unsync_amp 与 B0_unsync 对比）
已经解释了几乎全部“幅度收益”；恢复符号只多 +0.94 pp，不显著。
相位差多 +1.41 pp，也不显著。去掉 `log_power` 后 B0 仍为
**79.3%**（B0_nopow），说明简单总功率差不是主要驱动。

### 简单 m4 阈值

- 训练集选阈值 **m4=1.331**；成功 holdout 准确率 **69.95%**。
- m4 分布：holdout class10 mean 1.491 / median 1.355；
  class11 mean 1.591 / median 1.519——明显重叠，幅度不是干净分隔。

### 类别方向

| 子集 | B0_unsync | R_amp | R_amp+phase |
| --- | ---: | ---: | ---: |
| class10 成功（n=119） | 70.6% | **68.9%** | **72.3%** |
| class11 成功（n=94） | 85.1% | **94.7%** | **93.6%** |

R_amp 对 16QAM 有帮助（+9.6 pp），对 QPSK 反而下降（−1.7 pp）；
相位差对 QPSK 有帮助（+3.4 pp），对 16QAM 下降（−1.1 pp）。
方向不一致，进一步说明不能把总体 +1.4 pp 当成稳定相位收益。

### 交叠分层（成功子集）

| 层 | n | B0_unsync | R_amp | R_amp+phase |
| --- | ---: | ---: | ---: | ---: |
| clean | 60 | 93.3% | 95.0% | **96.7%** |

| strong ≥25% | 73 | **79.5%** | 79.5% | 78.1% |

clean 成功样本分类很高，但只有 60 个；strong 子集没有幅度/相位
增益。低交叠样本不是“分不稳”，而是**恢复成功的 clean 样本太少**。

### 小型 MLP 敏感性

| 特征集 | 3 seed 均值 |
| --- | ---: |
| B0_unsync | 78.1% ± 0.8 |
| R_amp | **83.7% ± 1.0** |
| R_amp+phase | 82.6% ± 0.7 |

MLP 上幅度有 +5.6 pp 的额外增益，但相位差反而 −1.1 pp；逻辑回归
上幅度只有 +0.94 pp。**幅度信号可能存在非线性收益，但不稳定，
不足以作为“恢复符号必要”的证据；相位差则没有可重复收益。**

## 5. 全实例净收益（失败回退 B0）

| 模型 | 全 holdout 准确率 | Δ vs B0 | 95% CI | 纠正/改错 |
| --- | ---: | ---: | --- | ---: |
| B0_unsync | 61.5% | — | — | — |
| R_amp + fallback | **62.8%** | **+1.28 pp** | [−0.72,+3.23] | 19 / 12 |
| R_amp+phase + fallback | **63.4%** | **+1.83 pp** | [−0.18,+3.95] | 24 / 14 |

逐类全实例：

| 类 | B0_unsync | R_amp+fallback | R_amp+phase+fallback |
| --- | ---: | ---: | ---: |
| class10 | 50.0% | 49.3% | 50.7% |
| class11 | 74.0% | **77.5%** | 77.1% |

净收益几乎全部来自 class11；class10 基本持平/略降。全实例 CI 均

若把对照换成 **B0_power**，R_amp+fallback 看似有 +11.2 pp；但那
主要是“未同步幅度统计”的功劳（B0_unsync 已达 61.5%），不是恢复
符号的独有收益。**B0_unsync 才是公平的本地基线。**

## 6. 独立判断

**幅度**：
- 有物理信号（m4 方向正确；class11 明显受益），但**不是恢复符号
  独有**。未同步局部 IQ 幅度统计已经达到 79.3%，恢复幅度 80.3%。
- 简单 m4 阈值只有 69.95%，幅度分布重叠；分类器收益主要来自
  幅度直方图/多特征，而非单一 m4。
- 结论：**保留简单方案；不把“必须做匹配滤波/符号定时”作为前提**。
  若只追求幅度判别，未同步幅度统计更省算力。

**相位差**：
- 总体 +1.41 pp，但 CI 包含 0；MLP 上为负；类别方向相反。
- 不满足“跨分类器/跨类别一致”的预注册判据。
- 结论：**不作为带回 Wi-Fi 的线索**；不扩大模型。

**恢复/交叠**：
- 恢复成功率 36.9%，strong 仅 28.2%；失败主要是线强度门限。
- 全实例净收益 +1.28/+1.83 pp，CI 包含 0。
- clean 成功子集分类 93–97%，说明特征不是主要瓶颈；**瓶颈是
  恢复覆盖率与交叠**。在解决恢复/标签可靠性之前，继续堆分类器
  不会改变结论。

## 7. 限制

1. 单一 70/30 文件级 split；holdout 成功实例只有 213，CI 较宽。
2. 恢复门限固定自 prior Phase A′/合成，未在 dev 上做全扫描；
   36.9% 是当前门限下的结果，不代表最优恢复率。
3. B0_unsync 是强基线（含未同步幅度/相位统计）；若只与 power-only
   比较，会高估“恢复符号”的价值。
4. 标签可靠性仍未全量验证；clean 成功子集只有 60 个 holdout 实例。
5. 类别功率有差异（holdout class10 log-power 均值 0.664 vs
   class11 0.593），但去掉 log_power 后 B0 仍为 79.3%，说明
   简单功率差不是主要驱动。
6. 未使用 val/test；结论不外推到预测框/级联场景。
