# Baseline-3 Phase B′ · 50×50 幅相直方图精确构造规范（锁定版）

2026-11-21。依据：Sensors 2026（P1）§3.1.1/§4.2/§5.2 的论文描述
（`paper_reproduction_audit.md` 引文 Q1–Q8）+ 官方 HF 数据集真实样本的
轴向实证。**无官方训练代码 → 本实现是"论文描述忠实重建"，不是
"官方模型复现"**（INFOCOM 官方仓库 `byungjunkim12/modulation_
classification_wifi6_5G` 存在，但其 Python 分箱 `imgData` 与 P1 论文有
已记录偏差：nanmax 而非 P99、奇数索引指示器会丢弃约一半落入偶数
bin 的样本、相位轴无 +π 平移——均不采纳，采纳 P1 论文规格）。

## 1. 轴向与分箱（经真实样本实证锁定）

**轴向勘误（2026-11-21）**：`paper_reproduction_audit.md` E6 初判
"行=相位"被官方数据推翻。实测 no_sync 集合（零同步误差、36 dB、
TGn 信道 A）四个 MCS 参照样本：

| 样本 | 行边际 | 列边际 | 解读 |
| --- | --- | --- | --- |
| BPSK(1bit) | 行 47/48/49 = 12/66/22%，其余≈0 | 列 {0,24,25,49} 各≈25% | 恒包络→幅度堆顶行；Δφ∈{0,±π}→3 相位位 |
| QPSK(2) | 行 47/48/49 堆顶 | 列 {12, 37, 24/25, 0/49} 各≈25% | Δφ∈{0,±π/2,π} 四值各 25%，理论逐位吻合 |
| 16QAM(4) | 行 {15/16, 35/36, 48/49} 三簇 | 列 8 个峰位 | 3 幅度级 + 8 相位差位 |
| 64QAM(6) | 行多簇散布 | 列近均匀 | 7 幅度级 + 12+ 相位位 |

**锁定：H[行, 列] = H[幅度 bin, 相位差 bin]。**

- 幅度轴（行）：`amp = A' / max(A')`，其中 A 为 128 符号块内全部
  数据子载波幅度池，A' 为剔除超过 P99 的离群值后的池（P1 Q2/Q3）。
  bin = `ceil(amp*50)-1`，clip 到 [0,49]。
- 相位差轴（列）：`Δφ = wrap_(−π,π](angle(Y^{s+1,k}) − angle(Y^{s,k}))`，
  `v = (Δφ+π)/(2π) ∈ [0,1)`（**+π 平移：Δφ=0 → 列 24/25 居中，±π →
  列 0/49 两端**——由 QPSK 参照样本四列位置实证）。
  bin = `ceil(v*50)-1`，clip 到 [0,49]。
- 归一化：直方图为计数；**训练输入按每实例 max 归一化**
  （P1 §4.2 Q7）。官方 .mat 工件存 sum=1.0（INFOCOM 式），加载时需
  转 max 归一化（E3，已记录差异）。

## 2. 散点配对（本规范绑定，论文未明说）

相位差按 E1 只在 8 符号组内相邻符号间计算（16 组 × 7 差 = 112 ×
52 子载波 = 5,824 对/直方图）。每对配对值为
`( |Y^{s,k}| , Δφ_k^{s→s+1} )`（对的首符号幅度）；P99 校准取自全块
6,656 值幅度池；**幅度超过块 P99 的对整对丢弃**（"outliers exceeding
the 99th percentile were discarded"）。合成参照的边缘结构与此配对
一致（BPSK/QPSK 恒包络不受配对选择影响；16/64QAM 的行簇为幅度级、
列峰为相位差值，配对方式只影响联合分布的细节）。

## 3. 符号组织与覆盖

- 一张直方图 = 128 个**原始时间上连续**的 OFDM 符号 = 16 组 × 8。
  实例行索引（`keep_idx`）切成最大连续游程，游程内切 128 符号块；
  只用完整 128 符号块；**不足 1 块则该实例无直方图并记录覆盖缺口**
  （禁止复制/填充凑数）。
- 每实例最多取最早 4 块（预固定，不调参）。
- 实例级预测 = 该实例全部直方图 softmax 均值后的 argmax。

## 4. 数据子载波掩码（真实占用验证后应用）

- 实际使用（经审计修正 2026‑11‑21）：
  - **W20**（64‑FFT）：`legacy_masks(64)` 返回 52 个占用 bin
    （±1…±26）与 4 个导频位置（±7, ±21），**实际传入直方图的是
    48 个 data bin**（占用集合减去导频）。`histogram_spec` 原文写
    "52 个非空 bin"是文档错误，实际代码始终用 `data`（48 bin）。
  - **W40**（128‑FFT）：`legacy_masks(128)` 返回 104 个占用 bin
    （±1…±52）与 8 个导频位置（±11, ±25, ±39, ±53），其中
    **±53 不在占用集合内**（占用集合止于 ±52），setdiff 自动忽略，
    无实际影响；**实际传入直方图的是 98 个 data bin**（104 减去
    占用内的 6 个导频）。原文写 "104 个非空"同样是文档错误。
- **模型有效性判定**：合成生成、缓存、直方图构建与 CNN 训练全部
  使用同一个 `legacy_masks` 函数的 `data` 输出（48/98 bin），内部
  完全一致。真实占用验证（in/out 18.0/12.0 dB，DC 空 bin 可见）
  确认这些 bin 含有信号能量。**已训练权重无需重训**——文档误差
  不影响实际特征提取。
- 标准参考：论文 P1 使用 52 个 bin（含导频），P2 官方代码用能量排序
  盲去 null。我们的实现选择了"data only（排导频）"路线，与 P1 论文
  描述有已记录偏差；两种路线在恒包络调制（BPSK/QPSK）下幅度差异
  为零，在 16/64QAM 下略有不同但被 CNN 的归一化吸收。

## 5. 输出

`float32 [1,50,50]`，per-instance max 归一化；同时保留原始计数与
覆盖统计（块数、可用符号数、丢弃行数）供验收与分层。
