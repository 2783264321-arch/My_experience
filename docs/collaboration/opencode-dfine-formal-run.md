# D-FINE-L 跨架构正式对照：验收、预算与运行记录

2026-11-22。三模型同口径：YOLO11s 过滤 mAP@0.5 **0.649725**，YOLO26l
**0.659601**；本场检验换 D-FINE-L 后窄带框在严格 IoU 下能否改善，同时保住
宽带分类收益。test 封存。

## 1. 位置编码复核（先决条件）

上游 `956d170` 的 2D sincos 位置编码方形约定为“前一半垂直（h/频率）、
后一半水平（w/时间）”。旧矩形补丁把两组顺序互换；已修正为 h 组在前、w 组在
后并保持 `(h,w)` 行优先。实测：方形逐位不变；矩形纵移只改前一半、横移只改
后一半；`[2048,512]` 验证缓存 `[1,1024,256]` 与动态网格 `allclose`。
详见 [dfine_pos_embed_audit.md](../../reports/detector_upgrade/dfine_pos_embed_audit.md)。

## 2. 正式入口验收

- 单通道迁移：官方 `dfine_l_obj2coco_e25.pth`；copied 1,156 / skipped 17
  （矩形位置缓冲、80→14 分类头、denoise 嵌入）；stem 求和 1；首层 `[32,1,3,3]`。
- 真实批次 8 视图 / 16 GT：loss 93.26，vfl 0.46 / bbox 3.57 / giou 2.18；
  梯度全部有限；空视图 + 真实视图 loss 110.5 有限。
- 归一化 cxcywh 全部在 [0,1]、宽高为正；样本内宽框 w=0.998、窄框 h=0.0008，
  解码每视图 300 框且都在 `[0,512]×[0,2048]`。
- checkpoint：模型/EMA 1,173 键、优化器 570 个 state；续训后 loss 90.7、
  epoch/step 正确。
- 峰值显存 **16.73 GiB**，稳定步时 **0.95 s**（8 视图 × 累积 2，BF16）。

## 3. 正式配置

| 项 | 值 |
| --- | --- |
| run | `dfine_l_c1_2048x512` |
| 初始化 | 官方 `dfine_l_obj2coco_e25.pth`（RGB stem 求和、14 类头/denoise 重初始化） |
| 数据 | C1 log-power 粗图 + 频率细片，单通道 `[2048,512]`；fit 5,957 / val 1,543 |
| batch | 4 源 = 8 视图，累积 2（等效 16） |
| 优化器 | AdamW，主 2.5e-4、backbone 1.25e-5、wd 1.25e-4，warmup 3 轮，余弦到 1% |
| 裁剪 / EMA | clip 0.1；EMA 0.9999（Ultralytics ModelEMA） |
| 冻结 | 上游 `freeze_stem_only`；新单通道 stem conv 可训练，norm 冻结 |
| 损失/匹配 | D-FINE 原生 Hungarian + VFL/L1/GIoU/FGL/DDF，含 denoising |
| 轮数 / 验证 | 50 轮 × 745 步；每 5 轮完整 val（24,975 视图）；best 按过滤 mAP50 |
| 片内规则 | postprocessor top-300/视图，无 NMS；之后走共同回映/边界/全局类 NMS/top-100 |
