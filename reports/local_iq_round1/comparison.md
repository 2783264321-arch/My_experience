## 4. IQ 特征单变量 AUC（train 侧诊断）

37 个物理特征中最大 |AUC−0.5|：012 = 0.067（box_to_cap_db）、
345 = 0.105（env_line_str）、1011 = 0.042（x2_line_mhz）。无任何特征
接近可用判别水平——框内窄带指纹对组内小类几乎不含单变量信息，
与 logistic 机会水平一致。

## 5. 功率基线的信息来源（margin=0 事后诊断）

框内 IQ 汇总特征无判别信息而功率裁块达 0.48–0.58，两者信息来源必然
不同。候选解释：①裁块 ±10% 边距携带框外邻接内容；②框内时频细纹理
携带弱类相关信息。用 **margin=0 紧框**重建全部裁块、其余配方不变、
seed 1729 重训（事后诊断，明确标注；`power_reps_m0.npz` /
`power_arms_m0.json`）：

| 组 | coarse m10 → m0 | local_power m10 → m0 |
| --- | --- | --- |
| 012 | 0.4700 → **0.5806**（+11.1 pp） | 0.4424 → 0.4839（+4.2 pp） |
| 345 | 0.4861 → **0.5820**（+9.6 pp） | 0.5294 → 0.5728（+4.3 pp） |
| 1011 | 0.5647 → 0.5592（−0.6 pp） | 0.5758 → 0.5565（−1.9 pp） |

**边距假说被否定：去掉边距不降反升。** 功率基线读的是**框内**的
时频细纹理——tone 位置/幅度/时间结构的细粒度模式，而非 ±10% 边距
里的邻接信号。这同时有两个推论：

1. 框内确实存在**弱、非调制**的类相关纹理（Phase A 已证调制不存在，
   故这是生成器与类别相关的伪迹，如逐类随机实现的 tone 模式/底纹），
   SmallCNN 能提取它，37 维 label-blind 汇总特征不能。逐特征 AUC
   （≤0.11）与 logistic 机会水平说明该纹理是高度非线性的空间/时间
   细节，不是任何单变量统计量。
2. **裁块配方本身是强变量**：proposal 框+m10（发表口径 0.4085）→
   GT 框+m10（0.482）→ GT 框 m0（0.581）。配方差异（+17 pp）远大于
   可分性研究里表示间差异（+2.3 pp）。既往裁块分类结论对几何配方
   高度敏感，应按配方口径比较。
