# D-FINE-L 细片 Wi-Fi 分类忽略 5 轮对照

2026-11-26。分支 `work/dfine-fine-wifi-ignore`。从第 25 轮 EMA 初始化，
跑 5 轮 control / ignore 对照，完整固定 `val`。未使用 test。

## 0. 结论先行

- **ignore 相对 control 没有有效增益**：mAP50 **−0.067 pp**、mAP50:95
  **+0.012 pp**；Wi‑Fi20 −0.33 pp、Wi‑Fi40 +0.34 pp、SRRC −0.23 pp，
  都在噪声量级。
- **两组 5 轮短训都明显低于第 25 轮**：control 0.742866/0.693956，
  ignore 0.742192/0.694079，相对 e25 的 0.761728/0.713928 约
  **−1.9/−2.0 pp**；SRRC 组两组都掉约 11.6 pp。
- 这说明本轮 5 轮、lr 1e-4 的继续训练本身太激进，e25 的 SRRC 峰区被
  破坏；ignore−control 的差值仍是有效的配对比较，但没有正收益。
- **判断：不保留 ignore 版本。** 分类忽略没有证明能改善系统 AP；
  5 轮短训预算也不适合从 e25 继续追 SRRC。
- 下一步不建议继续在同一预算上加码；FM 的几何缺失和合并 IoU 损失
  更值得单独实验。

## 3. 读数

- **ignore−control 基本为零**：整体 mAP50 −0.067 pp、mAP95 +0.012 pp，
  方向不一致；Wi‑Fi40 的两个类有 +0.84/+0.98 pp，但 Wi‑Fi20 三类全负
  （−0.42/−0.36/−0.22），SRRC 也小幅负。没有可保留的组级增益。
- **5 轮预算本身是主要退化源**：control 也掉 1.9/2.0 pp，SRRC 掉
  11.6 pp。e25 的 SRRC 峰区对学习率/继续训练很敏感，短训不能用来
  证明 ignore 无效，只能说明“在这个预算下无收益”。
- **分类忽略没有改变定位召回**（两组 0.9831），最终候选也几乎不变
  （154,174 对 154,300）；变化集中在分类分数和 SRRC 排序。
- **ignore 的分类准确率略高**（85.43% vs 85.27%），但没有转成 mAP；
  与上一轮局部残差的结论一致：分类准确率不是系统 AP 的充分统计量。

## 4. 判断

**不保留 ignore 版本，也不保留这次 5 轮短训预算。** 依据：

- 配对差值 ignore−control 在整体和三个目标组上都没有稳定正收益；
- 两组相对 e25 都明显退化，不能把退化解当作新基线；
- 细片 Wi‑Fi 分类忽略的机制是合理的，但在这套 lr/轮数下没有转化为
  系统收益；继续调同一预算的收益预期很低。

若仍要验证监督忽略，应另做**更温和的 2 轮 / 更低 lr** 诊断，而不是
把 5 轮 lr 1e-4 的结果外推。该诊断优先级低于 FM 几何。

## 5. 下一步

建议把下一项实验转到 **FM 几何/短窗**，因为证据更直接：

- 候选审计中 FM 全 query IoU 0.5 覆盖只有 77.7%，IoU 0.9 只有 65.1%；
- 固定框真值重标对 FM 只 +1.25 pp，说明分类不是 FM 的主因；
- 目标：先做 FM 缺失审计（按时长/带宽/SNR/边界/视图分层），再选
  短窗时间细化或完整目标采样；通过标准是 FM AP +≥3 pp，整体
  mAP50:95 +≥0.5 pp，其他组不回退。

宽带的下一步应等 FM 几何结论后再决定是否投入联合训练；不再继续
逐候选分类残差或同一预算的分类忽略。
