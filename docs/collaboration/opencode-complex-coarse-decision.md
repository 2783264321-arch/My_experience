# OpenCode 结果：复数粗图候选的独立审查与选择

依据 `docs/collaboration/README.md` 的「研究动机与取舍」和「下一轮共同决定
粗图前端」。本轮只做前端小对照，不训练检测器，不改原始 IQ/JSON；test 封存，
对照仍是 **0.649725**。

## 1. 先审查两条候选的判断

两种候选不是同一种算子：

- **稀疏 2048**：80 MHz 下 25.6 µs 的短窗复数测量，物理定义干净、开销低
  （80/150 约 0.05 s/样本），代价是帧间空档和 2048 行全频格比细片粗
  6.8–27.3 倍。
- **0.7 ms → 2048 重叠复数带**：0.7 ms 长窗的频率滤波复包络，100% 时间
  覆盖、带边可重建；代价是有效带宽约翻倍、带内相消更多、时间响应变长，
  不是短窗系数的直接替代。

上一轮有两个口径要修正：漏 bin 是 **157 / 17,619 个 GT 内列 = 0.89%**
（不是 157/38,912=0.40%）；2.94 ms 的边界 p90 是向外搜索 10 列的限制
（30–35 个 support 触边），不是真实边界误差。原始 train 最短标注是
**1 ms**（76 个实例子集最短 3 ms），不是 4 ms。本轮用已知边界的合成突发
补测。

## 2. 带边单音：重叠带能重建，单带 Hann 有零点

80 MHz，单音扫过带中心、两个带交界和观测带边缘。表中是相邻三个带
（b-1/b/b+1）的归一化响应，以 5.019531 MHz 带中心为 1。

| 单音 | sparse | 50% overlap | 单带 Hann | 矩形 |
| --- | --- | --- | --- | --- |
| 带中心 5.0195 MHz | 0.20 / 1.00 / 1.00 | 0.00 / 1.00 / 0.002 | 0.00 / 1.00 / 0.00 | 0.00 / 1.00 / 0.00 |
| 交界 5.000 MHz | 0.00 / 0.589 / 1.178 | **0.00 / 0.473 / 0.530** | 0.00 / 0.00 / 0.004 | 0.00 / 0.25 / 0.75 |
| 交界 5.039 MHz | 0.00 / 0.589 / 1.178 | **0.00 / 0.473 / 0.530** | 0.00 / 0.00 / 0.007 | 0.00 / 0.119 / 0.881 |
| 近边缘 39.5 MHz | 0.417 / 1.148 / 0.765 | 0.185 / 0.818 / 0.00 | 0.00 / 0.330 / 0.00 | 0.00 / 1.00 / 0.00 |
| 观测边 39.9 MHz | 0.238 / 1.038 / 0.958 | 0.006 / 0.997 / 0.00 | 0.00 / 0.992 / 0.00 | 0.00 / 1.00 / 0.00 |
| 观测边 -39.9 MHz | 0.165 / 0.958 / 1.038 | 0.00 / 0.986 / 0.017 | 0.00 / 0.949 / 0.00 | 0.00 / 1.00 / 0.00 |

50% overlap 的相邻响应和几乎恒为 **1.002–1.003**，包括两个带交界和观测带
边缘；单带 Hann 在 5 MHz 交界处和只有 0.004–0.007（零点），在 -39.5/39.5
也衰减到 0.223/0.330；矩形在交界处分成 0.25/0.75；稀疏没有零点，但会泄漏
到多行（相邻幅度和 1.8–2.3），不是干净的单行测量。

## 3. 同带双音：所有复数候选都有 ~2.7 倍相位起伏

两个单音在同一个粗带内（5.019531 MHz ± 2.5 kHz），相对相位 0、π/2、π：

| 相位 | sparse | overlap | 单带 Hann | 矩形 | overlap power | rect power |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 1.591 | 3.708 | 3.543 | 3.755 | 0.001379 | 0.001396 |
| π/2 | 0.715 | 1.659 | 1.590 | 1.680 | 0.001387 | 0.001404 |
| π | 0.588 | 1.362 | 1.306 | 1.379 | 0.001387 | 0.001404 |
| max/min | 2.71× | 2.72× | 2.71× | 2.72× | 1.006× | 1.006× |

**这是关键：50% overlap 只改善带边形状，不解决同带复数的相消。** 所有复数
候选都有约 2.7× 的相位相关幅度；功率通道只有 <1% 变化。两通道复数粗图
不能独自承担 14 类的能量/上下文。

## 4. 跨窗短突发：稀疏会漏 0.1 ms 中缝突发

80 MHz、150 ms，列间距 `h=0.294 ms`，突发在带中心；offset 0 在帧中心，
offset h/2 在最坏中缝。

| 时长/位置 | sparse | 稠密 2048 功率 | overlap 功率 | 0.7 ms 细片功率 |
| --- | --- | --- | --- | --- |
| 0.1 ms / 中心 | 检出 [256] | 检出 [256] | 检出 [256] | 检出 [256] |
| 0.1 ms / 中缝 | **漏检（SNR 0.1）** | 检出 [257] | 检出 [256–257] | 检出 [256–257] |
| 0.3 ms / 中心 | 检出 [256–257] | 检出 [256–257] | 检出 [256–257] | 检出 [256–257] |
| 0.3 ms / 中缝 | 检出 [257] | 检出 [257] | 检出 [257] | 检出 [257] |
| 1.0 ms / 中心 | 检出 [256–259] | 检出 [256–259] | 检出 [256–259] | 检出 [256–259] |
| 1.0 ms / 中缝 | 检出 [257–259] | 检出 [257–260] | 检出 [257–260] | 检出 [257–260] |

中缝边界误差：0.1 ms 时 sparse 漏检，dense 起点 +0.147 ms、终点
+0.047 ms，overlap/细片起点 -0.147 ms、终点 +0.047 ms；0.3 ms 时所有
support [257]，起点 +0.147 ms、终点 -0.153 ms；1.0 ms 时 sparse 终点
-0.266 ms，dense/overlap/细片终点 +0.027 ms。

结论：稀疏的空档对 0.1 ms 内部突发是真实风险；≥0.3 ms 能检出，但边界可差
约一列。0.7 ms overlap 能检出短突发，但**时间响应和 0.7 ms 细片一样被拉长**，
并不比细片更锐；稠密 2048 功率窗最短、覆盖 100%，是短突发/时间边界最好的
功率视图。overlap 的优势是带边重建和 100% 覆盖，不是时间锐度。

## 5. 真实 IQ 与开销

上一轮 14 个样本、76 个实例：

- 稀疏覆盖率：80/150 **8.7%**，40/150 17.4%，20/150 34.9%，80/20 65.4%，
  20/20 100%；
- 漏 bin 157/17,619 = **0.89%**，最差 12.1%（20 MHz/150 ms 的突发窄带）；
- 稀疏/稠密功率比中位数 0.998，连续信号能量基本无偏；边界 support 只作
  可见性检查，干净边界看上面的合成突发。

50% overlap 在同一批真实 IQ 上的 **sum-normalized coherence** 中位数
**0.145**（p10 0.073，p90 0.284）；单带 Hann 0.303，矩形 0.184，稠密 2048
复数 0.222。overlap 的有效带宽约翻倍，带内相消更多；这是带边重建的代价，
不是数值 bug。该 coherence 是归一化权重的诊断，不与单音绝对幅度直接比较。

开销（80/150，秒/样本）：细片 0.444，稀疏 0.049，稠密 0.408 + 池化 0.561，
0.7 ms 频率池化约 0.098。3 通道 overlap 复用细片 STFT，只多约 0.1 s 池化，
不需要额外 2048 点 STFT；C3 sparse 复用了现有功率粗图 + 稀疏复数，成本更低
但时间原子不一致。

## 6. 我的选择

**两条 2 通道复数候选都不作为主前端。选择 3 通道粗图：power + Re/Im，
全部来自同一份 0.7 ms STFT 和同一组 50% overlap 线性 Hann 带权重/时间中心。
保留“现有 0.7 ms 功率 + 稀疏 2048 Re/Im”的 3 通道低开销对照。**

理由：

1. 同带双音证明所有复数候选都有 ~2.7× 相位起伏，功率 <1%；两通道复数
   粗图无法同时承担能量/上下文和相位。power 通道不是可选项。
2. overlap 解决带边零点（相邻响应和 ~1.002），但有效带宽翻倍，复数相干度
   从单带 0.303 降到 0.145，同带相消仍在；它必须和 power 配对使用。
3. 稀疏是最便宜的干净复数测量，但 0.1 ms 中缝突发会漏，150 ms 突发窄带
   有 6–12% 弱 bin；适合作低开销对照/回退，不是全类主前端。
4. 3 通道 overlap 的物理定义最一致：power 用 `Σ w·|z|²`（带能量），
   Re/Im 用 `Σ w·z`（带复包络），三者同 STFT、同 512 帧中心、同权重；
   代价只是一个输入通道和约 0.1 s/样本池化。

如果必须只能两通道：

- 选 **稀疏 2048 Re/Im**，它是最干净的复数测量；不要把 2 通道 overlap
  当成免费升级。
- 若允许两个通道是不同物理量，选 **power + 稀疏 Re/Im**，用功率保能量、
  用稀疏复数保相位，这是避免相消的最小两通道方案。

## 7. 最小训练对照

同一 fit/val、proposal、512 帧中心、标签、检测器主体和训练预算，四个
2048×512 分支：

1. C2 sparse Re/Im；
2. C2 overlap Re/Im；
3. **C3 overlap：power + Re/Im（主候选）**；
4. C3 sparse：现有 0.7 ms 功率 + 稀疏 2048 Re/Im（低开销对照）。

先看 C3-overlap vs C2-overlap（power 是否找回同带/突发能量）、
C3-overlap vs C3-sparse（无空档/带边是否值这个成本），再看对 0.649725
功率 baseline 的配对增益。报告总 mAP@0.5、定位召回、0/1/2 与 3/4/5 AP、
10/11 和窄带类、重叠/突发子集和输入成本。固定子集 10–20 epoch 足以淘汰
前端；只有稳定配对增益才进入完整训练。test 继续封存。

证据：`reports/complex_coarse_candidate_comparison.json`、
`reports/complex_coarse_decision.md`；脚本：
`scripts/validate_complex_coarse_candidates.py`。上一轮报告已修正 0.89%
漏 bin、边界 p90 触边和最短 1 ms 的口径。
