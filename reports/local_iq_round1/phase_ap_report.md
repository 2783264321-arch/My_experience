## 4. 三轨道并行复核结果

### 4.1 轨道 E — 标注位置能量审计（46 帧，5 s）

- `target_at_label`（带内中位 ≥ 带外 +6 dB 且带内主峰 ≥ +10 dB）通过
  **35/46**（clean 26/32、overlap 3/8、**对照 BLE/Zigbee 6/6**）；
  全帧 in/out 中位 **+10.2 dB**。
- **无任何严格空框**（可评估帧带内峰值都 ≥ +7.1 dB 高于带外中位）；
  SRRC clean 8/8 通过且占用宽度 8.3–10.0 MHz ≈ 整框；WiFi clean
  20/24 通过、占用 13–36 MHz。目标类能量多呈"偏心"分布（|峰|中位
  3.7 MHz），对照类紧贴框心（51–433 kHz）。
- 负对照干净分离：合成白噪声 in/out ≈ 0.0 dB（0/4 过）、真实 +15 MHz
  诱饵带 ≈ −2 dB（0/4 过）。
- **旧解调定量证伪**：旧公式主峰落 ±B/2 附近且与"带内强峰帧"集合
  逐一重合（18/46）——round‑1 逐帧内容描述测在错位频带上。
- 11 个未过帧分类：2 个不可评估（框=全观测带）、7 个"标签处仅窄音"、
  2 个最接近空（`train/1620:1`、`train/1021:1`）。

### 4.2 轨道 W — WiFi CP‑OFDM 结构（30 帧，8 s）

- 合成标定（3 B × 3 numerology × SNR{∞,10,0,−5} + 15 噪声负例）：
  噪声最优 metric 0.114 / ratio ≤4.3；预注册 5× 门限会误杀 SNR=0 dB
  正例，按预注册调整程序取最大可用因子 → **门限 metric>0.342 且
  ratio>15**（SNR≥0 dB 全保留、噪声全灭，理由留痕）。
- **17/30 帧通过**（clean 15、overlap 2），**全部一致选中
  (T_u, CP) = (3.2, 0.8) µs**（SCS 312.5 kHz，legacy 风格 numerology），
  metric 0.66–0.96、ratio 18–374、cfo≈0 kHz；HE 候选 12.8 µs 从未胜出，
  其它 T_u 全停噪声位。**→ 这 17 帧的"无 OFDM 结构"结论归因于旧
  解调 bug，而非结构缺失。**
- 通过帧子载波 m4（n=600 符号，探索性）：QPSK 标签帧 1.04–1.47、
  16QAM 标签帧 1.38–2.05、64QAM 标签帧 1.44–1.50；**10/17 与标签
  理论值一致、7 失配**；QPSK vs 16/64 部分分离，16 vs 64（理论差
  0.06）当前不可分。
- 13 个未过帧归因（逐帧证据）：宽带能量无梳 5、窄带能量 3、无目标
  能量 5；边界帧 5 个带 sub‑floor 梳证据（ratio>15 但 metric<门限）；
  4 个重叠帧标注共信道污染可能。`train/1425` 特例：梳强但带内中位
  仅 1.2 dB，提示真实信号越出标签框。
- 实现注记：`cp_strip_fft` 的 CFO 符号约定取反传入（合成验证
  m4 修正 1.000 / 未修正 1.433 / 双倍 1.600）；B=bw 帧子载波噪声区
  为空、代理量无效并已标注。

### 4.3 轨道 S — SRRC 单载波结构（10 帧，18 s）

- 合成标定（2 α × 2 阶数 × 3 B，float16 往返）：R 估计误差 **0.0%**、
  α ≤15.1%；恢复定时下 m4 = 1.014–1.022（QPSK）/1.330–1.339
  （16QAM）。定时脆弱性量化：±0.25 符号定时错 → m4 膨胀至
  ~1.26 / ~1.50。literal W90/W10 宽度规则被证明有形状偏置
  （α 偏 +48~78%），改用 RC 代数精确的配对反演（误差 ≤18%）。
- **真实 10 帧：5 帧通过 SRRC 门限**（符号率音 > 阈值 0.0424 +
  RC 形 PSD + W50≈R）：**6 帧带精确 8.333 MHz = 10/1.2 符号率线，把
  滚降定标在 α=0.2**（与 round‑1 单帧偶见的 8.333 MHz 线呼应，本轮
  证明它是类级规律）；10% 边缘宽度 9.42–9.80 MHz（理想 9.32）确认
  RC 边沿，但 90% 平坦段宽度显示通带有 ≥10% 涟漪/倾斜——基于宽度的
  α 估计会过读（0.26–0.67 vs 真值 0.2），此警示已入报告。class‑10
  clean 三帧 m4 ≈ 1.01–1.14（贴 QPSK 参考值）；class‑11 两帧
  1.39–1.79（高于 16QAM 参考，低 SNR 向 Rayleigh 2.0 拉拽和/或非 QAM
  星座的可能）。噪声负对照：R 估计退化为全带宽、音强 ≤0.0098、
  m4≈2.0。
- 未过 5 帧：2 个重叠帧（污染）、`train/1160`（平坦 10 MHz 带、无
  符号率音、近 Rayleigh 包络——噪声样或 OFDM 样宽带内容）、
  `train/123`（内容偏心 −2.27 MHz、无相干音，且框触捕获端）。
- 实现注记：标定中发现共享 `gen_srrc` 辅助器在 8 sps/span‑8 设置下
  脉冲谱下垂 ~6.5%（`srrc_pulse_taps` 本身正确），S 轨道标定改用
  同一 taps 的 32 sps/span‑16（保真 ~0.6%）——该辅助器若再用于
  生成参考信号需注意此设置差异。
- 探索性类间趋势：class‑11 clean m4 均值 1.649 > class‑10 1.276，
  方向与 QPSK/16QAM 理论一致但不严格匹配（每组 n=4，含失配帧）。

### 4.4 跨轨道一致性核对

- E 的能量判定与 W 的结构判定**互补而非冗余**：`train/1024:0`、
  `train/1021:1` 在 E 判失败（带内中位在底噪附近）但 W 通过 CP 检测
  ——结构检测比能量判定更灵敏；反之 `train/208/123/1730` E 强能量
  通过而 W 无梳（宽带无结构能量）。两者无矛盾，测量的是不同层次。
- E 的 SRRC 占用宽度（8.3–10 MHz ≈ 整框）与 S 的 SRRC‑like 判定
  （RC 形 PSD、W50≈R）互洽。
- W/S 的噪声负对照与 E 的噪声/诱饵带负对照共同定义"什么都没有"
  的指纹，全部 0 过。

## 5. 问题 A / B / C 的回答

**问题 A：原始 IQ 提取是否可靠？——是（已验证事实）。**
证据链：① 26/26 合成单元测试（含 .bin 往返、5 种 B、负/偏心/边缘
频率、B 无关性、能量保持 1.000）；② 原始 FFT 地标与 JSON 标注仅在
"零频=观测中心"约定下吻合（3 样本、LoRa/BLE/Zigbee 窄带音逐一命中）；
③ 生产粗图行号与标签行一致（LoRa 标签行亮度 0.714 vs 全图 0.383）；
④ 真实对照类 6/6 通过、噪声/诱饵带 0/8 通过；⑤ 旧公式被定量证伪
（±B/2 位移与框内强峰帧完全重合）。

**问题 B：WiFi 和 SRRC 是否具有可恢复的调制相关结构？——
两族都有，但覆盖率与质量分层（事实 + 合理推断）。**
- WiFi：**17/30 帧存在强 CP‑OFDM 梳，全部 (3.2, 0.8) µs legacy
  numerology**；此结构在 round‑1 中被坐标错误掩盖。未过帧归因明确
  （无能量/窄带/宽带无梳/重叠），其中 5 个边界帧留有 sub‑floor 梳
  证据——"未检出"≠"不存在"，方法适用范围已由 SNR 扫描标定
  （≥0 dB 可检，−5 dB 不可检）。
- SRRC：**5/10 帧通过结构门限**（符号率音 8.333 MHz + RC 形 PSD），
  R 估计精确；定时质量是主要风险（±0.25 符号 → m4 显著膨胀），
  通过帧的符号统计呈 QPSK/16QAM 方向分离。
- 尚未验证：13 个 WiFi 未过帧与 5 个 SRRC 未过帧的结构缺失是
  真缺失还是低 SNR/重叠（需全量普查分层回答）；失配帧（WiFi 7 个
  m4 失配、SRRC 2-3 个）的来源（标签噪声 vs 同步残差）未定。

**问题 C：正确提取后的物理特征是否有潜在分类价值？——
有方向性迹象，未证明泛化（探索性结论）。**
- WiFi 子载波 m4：QPSK 标签组与 16/64 组部分分离（10/17 一致），
  但 16 vs 64 在 n=600 符号下不可分（理论差仅 0.06）——专家上限
  受此约束，需更长观测或相位域特征。
- SRRC 恢复符号 m4：class‑10（1.01–1.14）vs class‑11（1.39–1.79）
  方向分离、与理论部分一致，n=4/组。
- 三档证据分层：以上趋势属"合理推断"；"尚未验证"的是组内分类
  增益能否在独立验证里超过同框功率基线（round‑1 的功率基线走生产
  管线几何、不受坐标 bug 影响，仍可作 Phase B′ 对照：
  coarse 0.482/0.503/0.552、local_power 0.459/0.535/0.559、
  margin‑0 0.581）。
