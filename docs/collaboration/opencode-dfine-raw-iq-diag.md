# SpaceNet Wi‑Fi 结构审计与 raw IQ 表示诊断

2026-11-26。分支 `work/dfine-raw-iq-diag`。两部分：

1. 公开数据集信息 + 本地 Wi‑Fi CP/符号结构核查；
2. 在同一批固定 query 上比较“局部功率/物理摘要”和 canonical raw IQ 1D。

本轮未训练检测器，未使用 test。

## 0. 结论先行

- **公开资料没有逐信号协议/导频规范。** SpaceNet 2025 的官方说明只给出
  2.4 GHz ISM、混合信号、检测+分类任务、约 108G 数据；本地 JSON 只有
  类别/时间/频率，没有 802.11 协议、CP、导频、合成/实采标记。
- **本地 Wi‑Fi IQ 确实有 3.2 µs 量级的周期结构**，但与相位随机 surrogate
  的差异只有中等强度；不能据此假设所有 Wi‑Fi 都是同一种 802.11 协议。
- **当前 raw IQ 1D 诊断明显不如局部功率/物理摘要。** 在同一 val 子集上，
  raw IQ 的正类准确率为 0.310/0.331/0.540（012/345/1011），局部功率为
  0.384/0.457/0.602；keep recall 也更低。
- 这不等于“raw IQ 无用”，而是说明：
  **带限 + 2×带宽重采样 + 0.1 ms + 普通 1D CNN 这条具体路径不够。**
  下一步若继续 raw IQ，应做 CP/符号对齐的复数表示，而不是直接喂时域序列。
- 目前最确定的 pipeline 收益仍是 **Soft-NMS Gaussian σ=0.5**
  （0.765636/0.723509，+0.391/+0.958 pp）。

## 1. 公开信息

- 官方赛事：2025 全球“AI+无线电”挑战赛，复旦大学空间互联网研究院。
- 场景：2.4 GHz ISM，多设备混杂；初赛检测频率范围，决赛增加信号类型。
- 数据：官方称为低空频谱混合信号数据集，约 108G；一半合成、一部分实采
  后混叠（公开页未给逐样本源标记）。
- 本地：7,500 train / 2,500 test；fit/val 取自 train；JSON 字段只有
  `signal_id / start_time / end_time / start_frequency / end_frequency / class`。

公开资料没有给出：802.11a/g/n/ac/ax 的具体协议、CP 长度、FFT 大小、
子载波间隔、导频序列、SINR。因此不能把“Wi‑Fi”当成单一协议。

## 2. 本地 Wi‑Fi CP 结构核查

从 fit 抽 750 个 Wi‑Fi GT（B=20/30/40/50/80，每档 150），按 GT 时间/频率
裁局部 IQ，计算归一化 CP 相关：

- 对每个 lag，在 0.8 µs 窗口上滑窗计算
  `|Σ x[n]conj(x[n+lag])| / sqrt(Σ|x[n]|²Σ|x[n+lag]|²)`，取最大值；
- 同时做**相位随机化 surrogate**：保留幅度谱、打乱相位，破坏时间结构；
- 比较原始与 surrogate。

3.2 µs 结果：

| B (MHz) | 原始 p50 | 相位随机 p50 | 原始>随机 |
| ---: | ---: | ---: | ---: |
| 20 | 0.933 | 0.866 | 71% |
| 30 | 0.937 | 0.847 | 86% |
| 40 | 0.940 | 0.860 | 80% |
| 50 | 0.935 | 0.797 | 95% |
| 80 | 0.884 | 0.767 | 88% |

0.8/4.0 µs 也有类似但更弱的差异。解读：

- 3.2 µs 与 legacy 802.11a/g/n/ac 的 3.2 µs useful symbol 初步吻合；
- surrogate 基线也高（0.77–0.87），说明“最大相关”会被窄带/周期信号抬高；
- B=20/30/40 的显著性只有 71–86%，不是干净的全样本 CP；
- 合成/实采混合、重叠、CFO、噪声都会削弱；
- **旧实验的“同步可用率 67%/18%”是特定 CP/CFO 方法下的结果，不是数据集属性。**

因此 Wi‑Fi 分支应做**多假设 CP/FFT/CFO 搜索 + 置信度门控**，而不是硬编码
某个 802.11 协议；同步失败保留 raw IQ/包络分支。

## 3. Raw IQ 诊断

### 3.1 表示

对同一批固定 query 的预测框：

1. 取局部 IQ；
2. 按框频率带限；
3. 重采样到 `2×框带宽`；
4. 取中心 0.1 ms 物理窗口，pad/mask；
5. per-crop RMS 归一化；
6. 1D CNN（width 128，约 1.4M 参数），随机全局相位增广；
7. 组类 + keep 输出；CE。

训练/验证：fit 32k query（24k 正样本 + 7.9k keep 负样本），val 子集
23.5k；按 sample 划分 holdout。

### 3.2 结果

fit holdout：

| 组 | raw IQ 正类 | raw keep | 局部功率正类（旧） |
| --- | ---: | ---: | ---: |
| Wi‑Fi20 0–2 | 0.349 | 0.538 | 0.438 |
| Wi‑Fi40 3–5 | 0.336 | 0.720 | 0.467 |
| SRRC 10–11 | 0.576 | 0.611 | 0.727 |

同一 val 子集（用 `gt_iou>=0.5` 构造正样本）：

| 组 | raw 正类 | power 正类 | raw keep | power keep |
| --- | ---: | ---: | ---: | ---: |
| Wi‑Fi20 | 0.310 | **0.384** | 0.551 | **0.727** |
| Wi‑Fi40 | 0.331 | **0.457** | 0.759 | **0.826** |
| SRRC | 0.540 | **0.602** | 0.738 | **0.914** |

raw IQ 在三个组都不如局部功率，且 keep recall 明显更低。

## 4. 判断

**当前 raw IQ 路径不保留。** 这不是“raw IQ 一定没用”，而是：

- 0.1 ms、2×带宽、普通 1D CNN 没有把 CP/子载波/符号结构显式表达；
- 模型容量和训练预算虽然做了 1.4M/30 轮对照，但仍低于 ResNet18 的
  11M；
- 相位/CFO 未做符号级对齐，1D CNN 可能主要学到包络/能量，而不是调制；
- 正负样本分布仍有差距。

如果继续 raw IQ，下一版必须改成：

- **CP/符号对齐后的复数表示**（逐符号 FFT/子载波矩阵），而不是整段时域；
- 多假设 CP/FFT/CFO + 置信度门控；
- 同步失败保留 raw IQ/包络 fallback；
- 用同一 val 子集和同一分组分类预算验收。

## 5. 效率

- Wi‑Fi CP 审计从单进程逐窗口改为 **16 进程 + 累积和向量化**；
- fit raw IQ 32k query 提取 169 s，val 23.5k 提取 87 s；
- raw IQ 1D 训练 3 个组约 1 分钟/组（w128, 30 轮）；
- 下一步继续避免单核合并/AP，优先缓存和并行。
