# D-FINE-L 固定候选局部 IQ A/B/C 完整 val

2026-11-26。分支 `work/dfine-local-iq-abc`，基于
`work/spacenet-first-principles@2f04422`。冻结 D-FINE-L 第 25 轮，
固定同一批候选，比较：

- **A**：原检测器分数；
- **B**：局部功率残差；
- **C**：局部功率 + 30 维物理特征残差。

只做 `fit/val`，未使用 test，未改框、NMS 或候选身份。

## 0. 结论先行

- **A 精确复现**：`0.761728 / 0.713928`，最终候选 154,165。
- **候选级分类确实提高了**：匹配候选上的真类准确率，从检测器自身的
  17–22% 提高到 B 的 44–67%、C 的 44–73%。C 在 SRRC 上最好
  （72.7% vs B 67.2%）。
- **但系统 AP 全部下降**。最佳是 β=0.25 的 C：`0.757221 / 0.708658`
  （−0.45 / −0.53 pp）；B 为 `0.756935 / 0.708473`。β 越大掉得越多。
- Wi‑Fi20、Wi‑Fi40、SRRC 全部回退；FM 不变（本轮不改 FM 路由）。
- **判断：不保留 B/C，也不保留这条“冻结检测器 + 候选级 CE 残差”的
  路线。** 候选级准确率提高没有转化为系统 AP；问题在分数融合/排序
  校准，而不是候选覆盖或类别证据完全缺失。
- 若继续，下一步只做**列表级/AP 感知的候选重排器**，不再训练逐候选
  分类头；FM 的几何问题另开实验。

## 4. 为什么候选级准确率提高、系统 AP 反而下降

1. **逐候选 CE 不等于 AP。** 分类器在匹配候选上学到真类，但输出概率
   没有按检测器的分数尺度校准；把 logit 残差加到原分数上，会改变
   原本正确的候选排序，NMS/top100 随后丢掉高分正确框。
2. **训练分布与推理分布仍不同。** fit 正样本是 IoU≥0.5 的匹配候选，
   推理会路由所有预测 0–5/10–11 的候选；keep 头能挡掉一部分背景，但
   不能替代列表级校准。
3. **检测器原分数带上下文。** 局部裁剪只看到框内证据；D-FINE 的分数
   还编码多视图、query 交互和全局上下文。逐候选残差把强先验替换成
   弱局部先验。
4. **门控更新仍太“硬”。** 32k/49k 个高置信更新足以改变合并结果；
   错误更新集中在高分类置信但定位/上下文较弱的候选上。
5. **SRRC 的候选级准确率最高，但 AP 也下降。** 说明“能分对类”不等于
   “能排对序”；SRRC 原 AP 已较高，任何错误降分都会净损失。

## 5. 判断

**收尾本版，不保留 B/C，不把这条残差路线合入主线。** 依据：

- 系统 mAP50/95 在所有 β>0 下都低于 A；
- 三个目标组全部回退，没有“某个组稳定增益”可摘取；
- 候选级准确率提升是真实的，但当前融合方式不能把它转成系统收益；
- 继续调 β 只是在 A 与更差之间移动，不会产生正增益。

## 6. 下一步实验

只建议做**一个**不同层面的实验：**列表级/AP 感知的候选重排器**。

- 使用同一固定候选池、同一局部功率/物理特征，不新增候选、不改框；
- 输入加入原分数、类分数、带宽、view、局部质量；
- 训练目标改为同一图像内“正确候选应排在错误候选之前”的 pairwise /
  listwise 损失，或直接优化 soft-AP 代理，而不是逐候选 CE；
- 先在 fit holdout 锁定校准和阈值，再跑一次完整 val；
- 只有系统 mAP50:95 上升且 Wi‑Fi20/40、SRRC 不回退，才考虑 test。

若列表级重排仍不能把候选级准确率转成系统 AP，就停止“局部证据 + 冻结
检测器”这条线。FM 的框缺失是独立问题，另做短窗/时间细化或完整目标
监督实验，不和本轮混在一起。

## 3.1 单向提升诊断

为了判断负结果是否来自“错误降分”，同一批模型/候选再做一次单向残差：
只允许 `dz>0` 提升候选，不降原高分候选。β 扫描仍只是诊断。

| 模型 | mAP50 | mAP50:95 | Wi‑Fi20 | Wi‑Fi40 | SRRC | FM |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A | 0.761728 | 0.713928 | 0.5513 | 0.6558 | 0.7809 | 0.6456 |
| B 单向 β=0.25 | 0.761685 | 0.713641 | 0.5515 | 0.6556 | 0.7806 | 0.6456 |
| C 单向 β=0.25 | **0.762137** | **0.714251** | 0.5508 | 0.6575 | 0.7819 | 0.6456 |
| B 单向 β=0.50 | 0.761219 | 0.712857 | 0.5512 | 0.6542 | 0.7799 | 0.6456 |
| C 单向 β=0.50 | 0.762129 | 0.713850 | 0.5518 | 0.6566 | 0.7817 | 0.6456 |
| B 单向 β=1.00 | 0.760754 | 0.712059 | 0.5507 | 0.6537 | 0.7781 | 0.6456 |
| C 单向 β=1.00 | 0.761778 | 0.713005 | 0.5512 | 0.6557 | 0.7815 | 0.6456 |

- 去掉降分后，C β=0.25 从 −0.45/−0.53 pp 变成 **+0.041/+0.032 pp**；B 基本回到 A。
- 增益集中在 Wi‑Fi40（+0.17 pp）和 SRRC（+0.10 pp），Wi‑Fi20 仍 −0.05 pp；FM 不变。
- 这是 **0.04 pp 量级**，远低于 +1 pp 工程目标，也不能抵消训练/推理复杂度；按预定条件仍不保留。
- 结论：逐候选 CE 的问题主要是“降分伤排序”，单向能避免大损失，但剩余信号不足以构成可保留的系统增益。下一步应改训练监督或列表级目标，而不是继续调 β。
