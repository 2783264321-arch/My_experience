# SRRC 10/11 局部 IQ 分类 · 独立审查（实验前）

2026-11-21。对拟定思路的独立审查，先于任何 SRRC 训练/评估。
本轮冻结 Wi-Fi 专家，不接回 YOLO，不用 val/test。

## 0. 结论先行

**思路本身是合理的，但最可能的结果不是“相位差带来新收益”，而是以下三种之一：**

1. **幅度已经足够**：QPSK 的常模 vs 16QAM 的多档模长是物理差异；若幅度在
   同文件分组留出集上稳定优于局部功率/未同步 IQ，则简单方案即可，相位差
   只在有配对增益时才保留。
2. **幅度收益是功率/SNR 代理**：如果只做幅度而类别又与信号功率/SNR/时长
   相关，幅度分类器可能在后处理中“偷看”了条件差异。必须用功率-only 基线、
   分层和功率匹配子集检查。
3. **恢复成功率是主瓶颈**：Stage 0 显示约 80% 目标框有交叠、46–53% 强交叠；
   Phase A′ 只有 5/10 样本通过 SRRC 门限。若恢复成功率低，成功子集上的
   配对增益可能被“失败回退”抵消，净收益接近 0。

因此实验必须把**特征判别**与**符号恢复**分开归因；不要把成功子集上的
准确率当成端到端收益。

## 1. 已有证据

- Stage 0 数据审计：fit 10 MHz 档 **1,824 实例 / 1,572 文件**
  （class10 941/868，class11 883/824）；any-overlap 78–80%，
  强交叠 46–47%。
- Phase A′ 真实 SRRC：10 个样本，**5/10 通过 SRRC-like 门限**，
  **6/10 有约 8.333 MHz 符号率线**；class10 clean m4 ≈ 1.01–1.14，
  class11 clean m4 ≈ 1.39–1.79。样本极小，但方向支持“幅度有信息”。
- Wi-Fi 专家：恢复符号后的幅相直方图比功率图有约 +1 pp mAP；
  但**没有拆开幅度与相位差**，不能直接外推到 SRRC。
- 标签可靠性尚未全量验证；10 个样本不足以估计全量结构恢复率。

## 2. 主要风险

### R1. 标签/条件混淆

class10 与 class11 可能在不同文件、不同 SNR/功率/时长/交叠条件下出现。
若幅度分类器利用这些条件而不是调制阶数，留出集仍会“好看”，但不是
调制判别。**必须报告功率-only、未同步 IQ、元数据（功率/时长）基线，
并在功率匹配子集上复核。**

### R2. 恢复成功是后处理变量

只比较“恢复成功子集上的幅度 vs 基线”会改变样本组成。必须：
- 在**同一成功子集**上做配对比较；
- 在所有实例上做**失败回退**的净收益；
- 失败原因分桶计数，失败样本不能从分母删除。

### R3. 交叠污染

约 80% 框有交叠；强交叠可能把其他信号混入匹配滤波/定时。必须按
clean / any-overlap / strong 分层；若低交叠样本也分不稳，问题在特征
或标签，不在交叠。

### R4. 相位差的残余 CFO/定时

相邻符号相位差能消掉固定相位旋转，但残余 CFO 会产生跨符号相位斜坡，
定时误差会引入 ISI。必须：
- 只在**真正连续的符号**之间计算相位差；
- 做一次 label-blind 的全局圆均值去旋转（消固定旋转），但**不**用
  类别标签拟合相位校正；
- 把 raw 与去旋转的结果都记录，避免“相位差有用”其实来自残余旋转。

### R5. 分类器容量/特征维度

幅度与幅度+相位的特征维度不同；若用更大模型/更多参数，相位增益可能
是容量效应。必须用**同一轻量分类器、同一训练实例、同一正则化**，
并同时报告逻辑回归与小型 MLP 的敏感性。

### R6. 文件级泄漏

同一 IQ 文件多实例相关。必须按 `sample_id` 分组划分开发/留出；
超参数只在开发集内选；留出集只看一次。

## 3. 更省算力的做法

1. **先看单特征**：m4/m6、幅度直方图、功率-only 逻辑回归。若 m4 或
   功率已经分开，复杂模型没有必要。
2. **不做 CNN**：用标准化特征 + 逻辑回归（主）和 32 隐层 MLP（敏感性）
   即可；每个特征集训练秒级。
3. **不做全量 1,824 的重复大模型搜索**：固定超参 C=1、固定 2 ms 窗、
   固定 alpha/R 搜索网格；只做必要的敏感性（2 ms vs 4 ms、alpha 0.2 vs
   0.35 固定先验）。
4. **先做二分类 10 vs 11**：不先做 14 类，不接 YOLO。
5. **合成校准只做少量案例**：QPSK/16QAM × alpha {0.2,0.35} × B {20,40}，
   验证 R/alpha/timing 与 m4，不生成大数据集。

## 4. 预注册判据

- **幅度有价值**：在同一成功子集上，R_amp − B0_success ≥ **5 pp**，
  文件级 bootstrap 95% CI 下限 >0，且净全实例收益 ≥0；至少 2/3
  分折/种子方向一致。
- **相位差有额外价值**：R_amp+phase − R_amp ≥ **3 pp**，配对
  bootstrap 95% CI 下限 >0，且在逻辑回归与 MLP 两种分类器、以及
  clean/overlap 分层中方向一致；否则只记录为“未复现”。
- **停止扩大模型**：若 clean 子集二分类 macro-F1 <0.55，或净收益
  ≤0，或恢复成功率 <30%，不进入更大模型/更深网络。
- 若幅度收益只在强交叠子集出现，不列为稳健线索。
- 若功率-only 与幅度同水平，幅度收益归因于功率/SNR，不归因于调制。

## 5. 这些判断会怎样改变结论

| 观察 | 结论 |
| --- | --- |
| B0_power ≈ R_amp | 恢复符号不值；先解决功率/条件混淆或标签 |
| B0_unsync ≈ R_amp | 同步没有带来额外判别信息 |
| R_amp > B0，但净收益≈0 | 瓶颈是恢复成功率，不是特征 |
| R_amp > B0 只在 clean | 特征有效但交叠是部署瓶颈 |
| R_amp+phase ≈ R_amp | 相位差无可重复收益，保留简单幅度方案 |
| R_amp+phase > R_amp 且跨分类器/分层一致 | 相位差是值得带回 Wi-Fi 验证的线索 |
| clean 也接近随机 | 卡在标签/特征判别，不扩大模型 |

## 6. 本轮边界

- 只用 fit；val/test 不动。
- GT 框裁剪；不接 YOLO，不做预测框级联。
- 不重训 YOLO/Wi-Fi 专家；不训练大 CNN。
- 所有同步参数/门限 label-blind；留出集不调参。
- 结果写入 Baseline-3 共享记录，并明确区分“已验证/未验证”。
