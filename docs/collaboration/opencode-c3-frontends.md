## 问题

同一张原版 C1 全频功率图（`2048×512`，0.7 ms 面积加权）上，加入哪种复数相关
信息最能减少 Wi-Fi 调制错类（`0/1/2`、`3/4/5`）？

三组 C3 都保留原 C1 功率通道，只替换两个额外通道：

| 组 | 额外通道 |
| --- | --- |
| overlap | 0.7 ms 复数 STFT 沿频率做 50% 重叠线性 Hann 复带 |
| sparse | 原 512 帧中心直接做 2048 点短窗复数 FFT，半格对齐到粗图行中心 |
| dense | 2048 点短窗按约 10 µs 稠密采样，同频行前后帧归一化复相关，扣除行中心相位旋转，按帧对中点归入原 512 列 |

## 前端门结果（已通过）

合成单音放在粗图行中心，`b=500/1000/1500/1900`，20/40/80 MHz：

- sparse 峰值都在目标行，目标/邻行幅度比 **2.00**；未加半格移位的 2048 点
  FFT 峰值比 **1.00**，即能量分到相邻两行。半格移位的方向与幅度已核实。
- dense 在目标行的归一化复相关为 **1.0000 + ~1e-9 j**；512 列全部有帧对，
  最后一列至少 1 对，且两个帧中心都在 `n_ext` 内。
- 6 个真实样本（5/20/40/80 MHz，20/150 ms）上，功率通道与
  `build_sample_views(..., fine_indices=[])` **逐元素一致**。
- 前端耗时（秒/样本）：overlap 0.21–1.17，sparse 0.01–0.06，
  dense 0.09–1.40。按 1536 fit + 384 val 估计三套缓存约 **45.5 min**。

明细：`reports/c3_frontend_validation.json`、
`reports/c3_frontend_validation.md`。

## 训练口径（已启动）

- 固定分层子集 **1536 fit / 384 val**，seed 1729；同一功率缓存、同一标签、
  同一 `2048×512` 坐标。
- 4 个主臂 + 1 个 C1 第二 seed：
  - C1 power-only（1 通道，对照组）
  - C3 overlap / sparse / dense（3 通道，功率 stem 与 C1 相同，Re/Im 零初始化）
- 每臂 **20,000 optimizer steps**（不是完整 Baseline-0 37,250 步；8 小时内
  四臂全预算不可行，按要求改为同更新步数对照）。有效 batch 16，
  lr0=1e-3，warmup 2,000 步，cosine 到 1%。
- 每 1,280 步验证一次；连续 4 次没有 ≥0.001 mAP50 提升则早停；best EMA
  与 last EMA 都保存。C1 第二 seed 在 dense 缓存构建期间并行训练，充分
  利用 GPU/CPU，不让两个大模型同时抢显存。
- 主指标：总体 mAP50、AP_agn、定位召回、`0/1/2`、`3/4/5`、`10/11`、
  `9/12/13`，以及 0–5 混淆矩阵；绝对 mAP 不能与 0.6497 直接比，只看同
  子集/同步数的配对差。
- 资源：每套 complex cache 约 8 GB，单套存在；GPU 单任务运行，峰值预计
  ~10–12 GiB；缓存构建在 CPU 侧与 GPU 训练错峰/并行。
