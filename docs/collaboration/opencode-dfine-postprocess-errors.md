# D-FINE 后处理逐 GT 误差分解：覆盖已解决，分类排序才是瓶颈

2026-11-26。固定 D-FINE-L e25 + 742,414 个 val 候选，逐样本比较
NMS / Soft-NMS(σ=0.5) / WBF(0.55)，用 GT 做一对一匹配和逐 GT 归因。
未训练检测器，未使用 test。

## 0. 结论先行

1. **覆盖不是瓶颈。** 98.44%（NMS）/98.51%（Soft-NMS）的 GT 在
   IoU≥0.5 下已经存在**正确类**检测；漏检只有 1.5%，其中 85% 在候选
   池里连 IoU≥0.5 的框都没有。后处理无法救这些。
2. **瓶颈是分类排序。** 在已有正确类检测的 GT 中，最高分重叠检测是
   **错类**的比例：Wi-Fi20 **50.0%**、Wi-Fi40 **38.6%**、SRRC **32.3%**、
   窄带 **1.4%**。正确类检测存在，但被错类高分压住。
3. **FP 来源不是重复。** Wi-Fi/SRRC 的 FP 分数质量主要在
   **wrong_class**（Wi-Fi20 791 vs background 387；Wi-Fi40 458 vs 178；
   SRRC 459 vs 916）；窄带主要在 **background**（5,204）。重复 FP 的
   分数和只有 41–228（NMS），Soft-NMS 会增加重复，但 AP 仍上升。
4. **Soft-NMS +0.96 pp 的来源不是“多救回 GT”**（只多 5 个 GT），而是
   **background FP 减少 ~5–6k + 排序改善**；重复增加是代价，不是收益。
5. **全局/简单选择性 coarse+fine merge 不成立。** 38/40 MHz 信号在
   单个细片里根本装不下（同时有 coarse/fine IoU≥0.5 候选的 GT = 0）；
   merge 只有 1.4% 的 pair 能提升 IoU>0.05，平均增益为负。WBF 0.55
   的失败是结构性的，不是阈值没调好。
6. **局部证据硬改类/抑制/成对重排全部失败**：修正大多是同一 GT 已有
   正确检测的重复项，破坏是高分且唯一的正确检测。C 模型没有可用的
   成对排序信号（SRRC 甚至低于随机）。最后只剩现有 OFDM 专家的
   高分误检抑制 pilot。

## 1. 方法

- 固定 e25 候选池 `val_candidates.npz`（742,414 个候选，
  1,543 个样本）。
- 每个样本分别做 class-wise NMS(0.5)、Soft-NMS(0.5, σ=0.5)、
  WBF(0.55)，每类最多 100 个。
- 对最终检测按分数贪心做 **一对一 GT 匹配**（IoU≥0.5）。
- 每个 GT 记录：outcome（correct / unmatched_correct / wrong / missed）、
  最高正确类分数、最高任意类分数、重叠检测数、候选池里正确类/任意类
  候选数。
- 每个未匹配检测归类 FP 来源：background（不与任何 GT IoU≥0.5）、
  duplicate（与某 GT IoU≥0.5 且类相同）、wrong_class（与某 GT
  IoU≥0.5 但类不同）。
- 另做 coarse vs fine vs 分数加权融合，按 GT 带宽/时长分层；
  用 IoS（交小）区分包含关系。

## 7. 粗图 vs 细片 vs 融合（按 GT 尺寸）

对每个 GT 取 coarse（view_type=0）和 fine（view_type=1）里
最高分的 IoU≥0.5 候选，比较 IoU，并测试分数加权融合框。

| GT 带宽 | n | coarse+fine 都有 | coarse 更准 | fine 更准 | merge 增益>0 | 平均增益 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| <0.5 MHz | 2,188 | 2,095 | 33.2% | **66.8%** | 28.6% | −0.0143 |
| 0.5–2 MHz | 1,883 | 1,305 | **66.6%** | 33.4% | 25.4% | −0.0088 |
| 2–10 MHz | 1,215 | 484 | **74.2%** | 25.8% | 21.7% | −0.0127 |
| 10–25 MHz | 1,341 | **0** | — | — | — | — |
| 25–45 MHz | 441 | **0** | — | — | — | — |

- **窄带 <0.5 MHz：细片更准**（66.8%），符合“小信号靠细片”的猜想。
- **0.5–10 MHz：粗图更准**。
- **≥10 MHz：单个细片装不下完整信号**，coarse+fine 同时有候选的 GT=0；
  宽带只能靠粗图。这是结构性限制，不是模型没训好。
- 融合只有 21–29% 的 pair 变好，平均 IoU 为负；`merge_gain>0.05` 只有
  1.4%（55/3,884），`>0.1` 只有 0.4%（14/3,884），且几乎全在
  <0.5 MHz。**没有简单的 IoS/分数规则能高精度筛出正收益子集**
  （尝试 IoS≥0.0–0.6、分数比≥0.0–0.5，没有 precision≥0.35 且 n≥100
  的组合）。

结论：**按尺寸选择视图**（窄带用 fine，宽带用 coarse）是合理的；
**通用 merge 不是**。全局 WBF/NMM 会过度合并；只对窄带少数互补 pair
做选择性 merge，整体 AP 影响也只有 0.01–0.05 pp 量级。

## 8. 局部证据重排为什么失败

- 零训练诊断：C 模型 τ=0.9 高置信正类准确率 0.737/0.668/0.884，
  修正/破坏净值 +453/+1411/+722；但
  **478 个严格门控“修正”全部是同一 GT 已有正确检测的重复项，
  0 个 promotion；32 个“破坏”里 31 个是真实正确检测**。
- 硬改类：0.747249/0.704086（−1.84/−1.94 pp）。
- 门控改类：最好 0.764388/0.722433（−0.13/−0.11 pp）。
- 合并后改类：最好 0.764125/0.721996（−0.15/−0.15 pp）。
- 抑制：0.762555/0.720917（−0.31/−0.26 pp）。
- 新增候选：完全无变化（低分副本进不了 top-100）。
- C 模型成对信号：在 50.4%/39.1%/34.4% 的 ranking-loss GT 上，
  “正确框排在错框之上”的比例只有 58.4%/51.5%/28.1%；SRRC 低于随机。
- Oracle 上界：删除 score≥0.3 的纯 FP 可 +2.73 pp，但严格门控只能
  选到 score<0.3 的低分修正，天花板 +0.04 pp。**门控与 AP 质量在
  分数上是错位的。**

## 9. 下一步判断

1. **Wi-Fi 错类排序**是最大靶点（50%/39% top-1 wrong）。现有 C 模型
   已证明不够；唯一还没测的是已有 OFDM Δφ 专家在**高分最终检测**上的
   高置信分歧精度（pilot 进行中，sync 18.8%，低于 20% 预注册门槛）。
2. 若 pilot 诊断/AP 不过：**停止局部证据线**。可选项只剩
   - 检测器级整模型轻量微调（不是 21k 头，5 轮头已证明无效）；
   - 或接受 Soft-NMS 基线，工程化收尾。
3. **窄带 class 13 的 background FP** 是独立问题（5,204 分数质量），
   需要噪声/背景判别或 class-13 专用重排，不是 Wi-Fi 调制问题。
4. **后处理策略**：NMS/Soft-NMS 已接近该候选池的上限；NMM/WBF 的
   全局 merge 不成立，按尺寸选视图 + 少数组内 merge 只值 0.01–0.05 pp，
   不应优先。

### 12.3 为什么这次能成

- 误差分解已证明：Wi-Fi20 50%、Wi-Fi40 39% 的 GT 是“正确类存在但被
  错类高分压住”；错类 FP 的分数质量远大于重复/背景。
- 专家在高分、较干净的检测上条件准确率 0.719（YOLO cascade 全
  匹配只有 0.534），高置信分歧精度 99.4%。
- 动作是**删除高分错类 FP**，不是改类/加候选/低分重排；避免了我们

### 12.6 与信号物理带宽表的关系

用户提供的 GT 带宽表解释了粗/细结构：

## 13. test 后的三条筛选（val-only）

### 13.1 SRRC 高分抑制：不继续

- 现有 C 模型在高分最终检测上的高置信分歧精度 **61–86%**
