## 问题

同一张原版 C1 全频功率图（`2048×512`，0.7 ms 面积加权）上，加入哪种复数相关
信息最能减少 Wi-Fi 调制错类（`0/1/2`、`3/4/5`）？

三组 C3 都保留原 C1 功率通道，只替换两个额外通道：

| 组 | 额外通道 |
| --- | --- |
| overlap | 0.7 ms 复数 STFT 沿频率做 50% 重叠线性 Hann 复带 |
| sparse | 原 512 帧中心直接做 2048 点短窗复数 FFT，半格对齐到粗图行中心 |
| dense | 2048 点短窗按约 10 µs 稠密采样，同频行前后帧归一化复相关，扣除行中心相位旋转，按帧对中点归入原 512 列 |

## 前端门结果（已通过）

合成单音放在粗图行中心，`b=500/1000/1500/1900`，20/40/80 MHz：

- sparse 峰值都在目标行，目标/邻行幅度比 **2.00**；未加半格移位的 2048 点
  FFT 峰值比 **1.00**，即能量分到相邻两行。半格移位的方向与幅度已核实。
- dense 在目标行的归一化复相关为 **1.0000 + ~1e-9 j**；512 列全部有帧对，
  最后一列至少 1 对，且两个帧中心都在 `n_ext` 内。
- 6 个真实样本（5/20/40/80 MHz，20/150 ms）上，功率通道与
  `build_sample_views(..., fine_indices=[])` **逐元素一致**。
- 前端耗时（秒/样本）：overlap 0.21–1.17，sparse 0.01–0.06，
  dense 0.09–1.40。按 1536 fit + 384 val 估计三套缓存约 **45.5 min**。

明细：`reports/c3_frontend_validation.json`、
`reports/c3_frontend_validation.md`。

## 训练口径（已启动）

- 固定分层子集 **1536 fit / 384 val**，seed 1729；同一功率缓存、同一标签、
  同一 `2048×512` 坐标。
- 4 个主臂 + 1 个 C1 第二 seed：
  - C1 power-only（1 通道，对照组）
  - C3 overlap / sparse / dense（3 通道，功率 stem 与 C1 相同，Re/Im 零初始化）
- 每臂 **20,000 optimizer steps**（不是完整 Baseline-0 37,250 步；8 小时内
  四臂全预算不可行，按要求改为同更新步数对照）。有效 batch 16，
  lr0=1e-3，warmup 2,000 步，cosine 到 1%。
- 每 1,280 步验证一次；**本轮固定跑满 20,000 步，不早停**，以保持同更新
  步数对照；best EMA 与 last EMA 都保存。早停留给后续完整预算实验。
  C1 第二 seed 在 dense 缓存构建期间并行训练，充分利用 GPU/CPU，不让
  两个大模型同时抢显存。
- 主指标：总体 mAP50、AP_agn、定位召回、`0/1/2`、`3/4/5`、`10/11`、
  `9/12/13`，以及 0–5 混淆矩阵；绝对 mAP 不能与 0.6497 直接比，只看同
  子集/同步数的配对差。
- 资源：每套 complex cache 约 8 GB，单套存在；GPU 单任务运行，峰值预计
  ~10–12 GiB；缓存构建在 CPU 侧与 GPU 训练错峰/并行。

### 独立判断

1. **0/1/2 没有稳定收益。** overlap 两 seed 0.3019 / 0.2473（差 5.46 pp），
   sparse 0.2819 / 0.2336（差 4.83 pp），dense 0.2452；C1 mean 0.2625。
   seed1729 的 overlap/sparse 增益没有复现，不能写成稳定结论。
2. **3/4/5 是唯一跨 seed 复现的收益。** overlap 两 seed 0.4012 / 0.3940，
   mean +4.01 pp；dense 单 seed +10.70 pp（错类 79→69）点估计最大；
   sparse 0.4213 / 0.3270 不稳。若只追 40 MHz Wi-Fi，dense 最值得做
   第二 seed + zero-complex 对照，overlap 是已复现的保守选择。
3. **sparse 的总体 +2.51 pp 是 seed 波动。** 第二 seed −2.51 pp，mean
   与 C1 持平；10/11 的 +7.63 pp 也未复现（0.6082→0.4703）。不采纳
   sparse 作为总体最优。
4. **dense 是 3/4/5 专用，不是全局替换。** 它提高 3/4/5，但 0/1/2、
   10/11 变差；总体 +0.73 pp 不足以全局替换 C1。
5. **容量混杂仍在。** C1 是 1 通道，C3 都是 3 通道；增益可能来自额外
   容量/优化，而不是复数信息。需要 **C3-zero-complex** 控制才能因果归因；
   上一轮 coarse+fine 审计也有同样限制。

### 推荐

- **不建议**用任一 C3 前端全局替换 C1 功率基线。
- 若论文/业务重点是 **40 MHz Wi-Fi（3/4/5）**：优先复核 **dense**（点估计
  最大）和 **overlap**（两 seed 稳定），并加 **C3-zero-complex** 控制与
  至少一个额外 seed。
- **20 MHz（0/1/2）**：本轮没有稳定复数前端收益；保留 C1 或另做针对性
  相位/通道设计。
- 本轮是 1536/384 子集、20k steps、best EMA 的筛选；绝对 mAP 不能与
  0.6497 直接比。test 未打开。

### 判断

- **没有复数前端在总体上超过 zero3 无信息对照**：zero3 0.5156 >
  dense 0.5123 > overlap 0.5078 > sparse 0.4998。C1→复数的总体提升在
  架构/seed/训练波动范围内。
- **长窗 overlap 的 3/4/5 增益也不是复数信息效应**：虽然 overlap 相对 C1
  两 seed 都涨（mean +4.01 pp），但同架构 zero3 的 3/4/5 为 0.4198，
  高于 overlap 的 0.3976；只有 dense 超过 zero3。
- **0/1/2 不是复数信息的收益**：zero3 最好（0.2834），dense 更差
  （0.2619）。
- **40 MHz 3/4/5 有一个小且方向一致的 dense 残差**：+3.45 pp（best mean），
  两 seed 同向；common-box 分类 +2.95~+5.95 pp 同向，但 McNemar p>0.2，
  且召回不升。属于“值得小规模复核”的信号，不是可采纳的结论。
- **是否扩大实验：暂不跑全量。** 建议先做 dense vs zero3 的 3–5 seed、
  768+ val、并加入 power+power+power/随机活通道的**活容量**对照；只有
  3/4/5 残差在更多 seed/更大 common 集上仍成立，才扩到完整 37k/full val。
  0/1/2 和 overall 不建议扩大。
- test 继续封存。
