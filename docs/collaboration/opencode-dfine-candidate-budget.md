## 0. 结论先行

- **K=300 精确复现原 AP**：`0.7617281486212556 / 0.7139283283253144`，
  与既有第 25 轮结果逐位相同。
- **候选上限不是当前瓶颈**：K=100 为 `0.761177 / 0.713777`（−0.055 /
  −0.015 pp），K=600 为 `0.761711 / 0.713909`（−0.002 / −0.002 pp）。
  K=600 没有收益；K=100 只损失 0.05 pp 量级，可作工程省候选的选项，
  但不值得作为研究实验。
- **Wi‑Fi20/40、SRRC 的框和正确类别候选几乎都在**：IoU 0.5 下 K300
  类正确覆盖为 **99.8% / 99.8% / 99.4%**；合并后仍为 99.4% / 99.3% /
  99.6%。问题主要是类别分数与排序，不是候选预算。
- **固定框真值重标的增益集中在宽带与 SRRC**：K300 最终候选上做一次
  一对一 IoU 0.5 重标，mAP50 从 **0.761728 升到 0.928729（+16.70 pp）**，
  mAP50:95 从 **0.713928 升到 0.871816（+15.79 pp）**。Wi‑Fi20
  **+35.27 pp**、Wi‑Fi40 **+28.91 pp**、SRRC **+18.51 pp**，FM 仅
  **+1.25 pp**。这是诊断值，不是可达上限；它保留框和原分数，因此仍含
  排序、重复框和合并损失。
- **FM 的框在全 query 中就不完整**：IoU 0.5 只有 **272/350（77.7%）**
  的 FM GT 在全 300 个 query 框中有匹配，K300 解码 77.1%，合并后 74.9%。
  IoU 0.9 时全 query 只剩 **65.1%**，合并后 51.4%。FM 的主因是几何/
  表示缺失，不是候选预算或类别分数。
- **下一步实验建议：给 Wi‑Fi20/40 与 SRRC 做候选级局部 IQ 调制证据
  分支（A/B/C 对照），不要继续调 K 或只训分类头。** FM 需要单独的
  几何/短窗实验，不应和宽带分类混在同一轮。

## 1. 口径

| 项 | 设置 |
| --- | --- |
| 权重 | 第 25 轮 `best.pt` EMA |
| 数据 | 固定 `val`，1,543 文件、7,162 GT、24,975 视图 |
| 输入/批 | C1 粗细视图，`batch_views=8`，BF16 |
| 解码 | 每视图 Q=300，14 类 sigmoid，conf 0.001 |
| 合并 | 边界过滤 → 细片 0–5 过滤 → 类内 NMS IoU 0.5 → 每样本前 100 |
| 预算 | K=100 / 300 / 600 个 query×class 候选/视图 |
| 重标 | K300 最终候选，一对一 IoU 0.5 类无关匹配，把匹配候选标签改为 GT 真类；框和分数不动 |
| 耗时 | 单次前向 + 三预算后处理 + 覆盖/重标：395 s |

逐阶段定义：

1. **全 query 框**：每视图 300 个 query 的框，未经分数 top-k；
2. **K300 解码**：300 个 query×class 组合，conf≥0.001；
3. **K300 解码·类正确**：在 2 的基础上要求候选类别等于 GT；
4. **K300 过滤后**：边界过滤 + 细片 0–5 过滤；
5. **K300 合并后**：类内 NMS 0.5 + 每样本前 100。

除第 3 阶段外，其余阶段都是一对一覆盖；第 3 阶段没有一对一，显示
类正确覆盖数。重标是诊断，不是数据集理论上限。

### 读数

- **Wi‑Fi20/40 是最大的分类空间**：重标后 AP50 到 0.9041/0.9448，
  距离 1.0 还有 9.6/5.5 pp。这 9.6/5.5 pp 是框、重复和分数排序的

- 因为重标保持原分数，上述增益包含了“正确类候选的分数是否够高”的

- IoU 0.5 时，全 query 已有 **78/350（22.3%）** 的 FM GT 没有任何匹配框；

  只做分类头不会解决 FM。

## 6. 判断与下一步实验

### 6.1 候选预算

**K=300 不是瓶颈。** 它精确复现原 AP；K=600 无收益；K=100 只损失
0.055 pp mAP50、0.015 pp mAP50:95，却少 23% 最终候选。K=100 可以作为
部署/吞吐的工程选项，但不值得作为研究实验；精度实验继续用 K=300。

### 6.2 新信号表示放在哪里

**优先放在 Wi‑Fi20/40 与 SRRC 的候选级调制证据，而不是候选预算或
再训分类头。** 依据：

- 这三个组的框和正确类别候选在 K300 中已接近全覆盖；
- 固定框重标的分类空间为 +35.27 / +28.91 / +18.51 pp；
- 只训 `dec_score_head` 的 5 轮短训已经证明，冻结 C1 特征上的线性
  重加权拿不到这部分空间。

**下一步实验（只做这一个）：候选级局部 IQ 调制残差 A/B/C。**
冻结第 25 轮检测器，用预测框中心/带宽从原始 IQ 读出局部复数波形，
低通抗混叠降采样后产生三组物理量：长/短窗功率变化、SRRC 包络与
高阶矩、Wi‑Fi 候选级短 FFT 子载波证据。三列同一完整 `val`：

| 列 | 输入 | 回答 |
| --- | --- | --- |
| A | 原 D-FINE | 基线 |
| B | 候选级局部 C1 | 只看局部时频功率是否够 |
| C | 候选级局部 C1 + 物理量 | 物理量是否在 B 之上有增益 |

框、分数排序和原 NMS/前 100 保持不变；B/C 只在匹配候选上输出组内
logit 残差，初始残差为零。先看 Wi‑Fi20/40、SRRC 的 AP 和系统
mAP50:95 是否同时上升；若只有局部分类准确率上升而系统 AP 不升，停止。
FM 不并入这一轮：它的缺口在框，应另做短窗/时间细化或完整目标监督的
几何实验。

### 6.3 工程效率

本次审计已经用一次前向复用了 K100/300/600 和全部覆盖统计；后续同类
实验应继续缓存“IQ → 视图张量”和原始 query 输出，避免重复物理变换和
前向。K=100 的 −0.055 pp 可作为吞吐选项，但当前精度优先，默认 K=300。
