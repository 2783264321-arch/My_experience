# Baseline-3 Phase B′ · 阶段 0：OFDM 前端修复与验收

2026-11-21，OpenCode。任务契约的两个已知实现问题（A/B）已修复并通过
合成端到端验收。HEAD 基准 `09a1bf7`；本目录全部文件未提交。

## 1. 修复内容

**问题 A（合成标定不符真实频带场景）**——`scripts/baseline3b_ofdm_frontend.py`
的 `gen_ofdm_baseband + embed_capture`：

- OFDM 在**目标带宽速率**生成（20 MHz→64 点 FFT、40 MHz→128 点，
  Tu=3.2 µs，SCS=312.5 kHz），legacy 参考布局（20 MHz：52 占用 =
  48 数据 + 4 导频，±26 bin，DC/保护带置零；40 MHz：104 占用 =
  **98 数据 + 6 个占用内导频**；`legacy_masks(128)` 的 ±53 导频
  不在 occupied 集合内，故不是 96/8）；
- `resample_poly` 精确有理重采样到捕获率（比值 1/1.5/2/2.5/4，
  抗混叠由滤波器保证）；
- 以**正确中心参考约定**上变频到合法带内偏移（含贴边偏移），随机
  符号起点、可选 CFO/带内 SNR，float16 往返模拟真实存储。

**问题 B（CP 搜索未覆盖完整循环相位）**——`cp_scan_full`：

- 共轭积 `c[n]=x[n]·conj(x[n+T_u])` 的 CP 窗和在**原始数组**上一次
  性累计（`S[i]=Σ_{m<cp} c[i+m]`），每个残差 j∈[0,T_sym) 取等数量
  窗口累加——包括跨周期边界的窗口，且**等窗口数消除了残差间偏置**；
- 检出的 `phi` 即符号起点残差，CFO 取最优窗相位。

## 2. 验收电池（`scripts/baseline3b_frontend_test.py`，38/38 通过）

| 测试 | 内容 | 结果 |
| --- | --- | --- |
| T1 | 8 种 (B,bw) × 合法偏移（含 0.97×最大偏移贴边）× 3 阶数 × 4 随机起点/配置 | 全部选中 (3.2, 0.8) µs，min metric 0.88（门限 0.34），CFO 误差 ≤0.3 子载波内 |
| T1b | 起点扫满整个周期 | metric 波动 **0.1%**（启动不变） |
| T2 | 剥离+FFT 后数据子载波星座 m4 | **1.000 / 1.322 / 1.379**（理论 1.00/1.32/1.38），B∈{20,40,80} 全过 |
| T3 | 无 CP OFDM、纯噪声负对照 | 全部失败规则（metric≤0.15 或 ratio≤3.3） |
| T4 | 真实 IQ 地标（1058/3663 JSON 窄带音） | 中心参考约定下逐一命中 |

**T2 过程中发现并修复的第三个问题**：剥离后的符号行中，信号前后的
零填充/瞬态行（数值残渣呈 Rayleigh、行内 m4≈2）会把池化 m4 抬高
~0.16。修复：`filter_symbol_rows` 按行内带能量 <0.5×中位 过滤
（label-blind，仅能量），过滤后 m4 与理论逐位吻合。这也确立后续
直方图构建的规范：**只用连续、在信号内的符号行**。

## 4. 候选参数与禁止事项

- (Tu=3.2 µs, CP=0.8 µs) 是 Phase A′ 的首选候选，检测网格仍为完整

## 5. 阶段 1 验收（直方图构建，`histogram_battery.json`）

- **A · 合成端到端签名 vs 官方数据集**：BPSK/QPSK/16QAM/64QAM 经
  全前端（嵌入→提取→同步→剥离→直方图）的行/列边际与官方 HF 样本
  逐位一致——BPSK/QPSK 行堆顶（恒包络→幅度归一后 ≈1）、QPSK 列
  {0, 12, 24/25, 37, 49}（四相位差理论位）、16QAM 三幅度簇、
  64QAM 全散布。**轴向/平移/分箱约定经真实参照样本裁决**（行=幅度、
  列=相位、+π 平移；E6 初判被推翻并已在 histogram_spec.md 记录）。
- **B · 真实占用验证（E4 门）**：W20 in‑mask/out‑mask = **18.0 dB**、
  W40 **12.0 dB**；DC 空 bin 清晰（0.23–0.29 vs 邻 0.7–0.8）——
  legacy 52/104 掩码在真实数据上确认后锁定。修复过程中发现并修正
  一个掩码选择 bug（掩码须按目标带宽而非捕获 FFT 长度选择）。
- **C · 真实质量集**：18 帧（每类 clean×2 + overlap×1，B 覆盖
  40–80）全部产出有效直方图（非空、非 NaN、形状/归一化合规），
  代表图存 `histogram_images/`；2 个 sync‑fail 样本留档（c5
  `train/10`、c0 `train/1009`）。
