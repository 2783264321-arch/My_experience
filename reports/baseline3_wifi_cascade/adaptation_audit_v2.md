## 5. 样本量评估与风险

| 条件 | 评估 |
| --- | --- |
| E1（纯 predicted 微调） | 671 块 / 171 独立对有类不平衡（W40 4/5 类仅 40/36 块）——**偏薄**，需小学习率+早停，预期仅能小幅调整 |
| E2（GT+Pred 混合 1:1） | ≈1,355 块，类不平衡仍在，但 GT replay 缓解遗忘——**可行** |
| E3（GT jitter） | 从 fit 原训练 GT 框出发，量级最大；扰动分布将从本审计的几何偏差统计推导 |
| final-dev 评估 | 37 sync_ok（147 块）——CI 宽，结论需按实例级 bootstrap 报告 |
| 划分独立性 | final-dev 是内部开发留出（val 此前参与过决策），非完全独立测试 |

## 6. 是否具备进入微调的条件

**具备（以 E2 为首选，E1 为下限对照，E3 为低成本对照），但须接受
两点现实**：① W40 16/64QAM 的微调样本极少，任何该类增益都不足
以支撑独立结论；② final-dev 的 37 个有效实例决定了评估 CI 宽度，
不得把点估计差异过度解读。正式微调前建议先确认 E2 的 GT replay
块生成脚本与 1:1 比例（预注册，不看 final-dev 调整）。
