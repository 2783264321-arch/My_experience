| 项 | 设置 |

## 4. 读数

1. **第 50 轮的问题与 val 完全同向，而且更重。** SRRC 两类在 test 上
   分别掉 14.63 / 12.12 pp，Wi‑Fi20 三类掉 2.7–5.0 pp；FM 反而 +1.03 pp。
   这再次说明第 50 轮不是框退化，而是 SRRC/Wi‑Fi20 的类别分数与排序退化。
2. **第 25 轮到 test 的下降是整体性的。** 四份模型都掉约 2.1/3.2 pp，
   test−val 差距接近；第 25 轮在 test 上仍领先所有变体。官方 test 的
   SRRC 比例更高（2,067/20,018 = 10.3%，val 为 716/7,162 = 10.0%），
   但不足以解释第 25 轮与第 50 轮之间 13 pp 的 SRRC 差。
3. **分类头短训在 test 上仍无收益。** control/group 都只比第 25 轮低
   0.22/0.31 pp；group 相对 control 的 +0.006/−0.006 pp 是噪声。
   Wi‑Fi20 `0/1/2` 没有一项稳定超过 control，SRRC 的 +0.10 pp 也补不回
   1.1 pp 的总体回退。test 结论与 val 一致：**不值得保留**。
4. **候选数接近每样本 100 的上限。** 四份都是 249.5k–249.9k / 2,500 样本
   （约 99.8/样本），合并与 top-100 行为没有被分类头训练改变；差异主要
   来自分数排序，而不是框数量或定位召回（0.9772–0.9795）。

## 5. 建议

- **最终模型：第 25 轮 `best.pt`。** 不保留第 50 轮，不保留 control/group。
- 不再做分类头短训或 `0/1/2` 组内 CE；test 已经确认这条路没有收益。
- 如果 Wi‑Fi20 仍是下一阶段重点，只建议再试**一个**不同层面的改动：
  在冻结的第 25 轮候选上训练轻量 `0/1/2` 候选级重排器，重排后再走原
  NMS/前 100；只有在 val 上升且 test 最终确认不降时才保留。
- `test` 已按用户要求解封一次。后续改动仍只在 `val` 上迭代，`test` 只做
  最终确认，避免把 test 变成调参集。
