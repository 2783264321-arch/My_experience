## 待验证假设

1. **Raw IQ 1D**：按物理时间/带宽归一化后，是否比局部功率/摘要提供额外调制信息。
   - 不能把整段 150 ms 拉伸成固定图片；
   - 频率按框带宽带限并定采样率，时间按固定物理窗口切分/聚合；
   - 同步失败保留 raw IQ/包络分支。
2. **Wi‑Fi 协议/CP 结构**：fit 抽样 750 个 Wi‑Fi GT，3.2 µs 最大 CP 相关中位数
   0.88–0.94，相位随机 surrogate 0.77–0.87，原始>随机 71–95%。初步支持
   3.2 µs 周期结构，但**不足以假设所有 Wi‑Fi 都是同一 802.11 协议**；公开资料
   没有逐信号协议/导频信息。
3. **SAHI 2.0 跨视图关联**：Soft-NMS 已证明合并是短板；候选图/学习关联是否
   比 Soft-NMS 更好，尤其高 IoU/重叠。
4. **FM 几何**：全 query IoU 0.5 覆盖 77.7%，0.9 只有 65.1%；固定框重标只
   +1.25 pp。需要短窗/时间细化或完整目标采样。

## 效率教训

- 16 vCPU、大内存、4090；CPU 100% 平台 = 单核，不是“机器忙”。
- Soft-NMS 逐框 `torch.cat` → alive 掩码，固定候选池单次合并 **82 s**；端到端
  val 仍约 800 s，主要受两次合并/AP 和模型前向影响。
- Wi‑Fi CP 审计单进程逐窗口 3 分钟不出结果；改 16 进程 + 累积和向量化后几十秒。
- 后续：合并/AP 按样本并行或 GPU；预处理与 GPU 推理重叠；缓存 IQ→视图、
  候选、局部特征；避免重复前向。

- **诊断**：3,438 个 score>=0.3 检测，sync 18.8%（646）；matched
  630 上检测器准确率 0.375、专家 0.719；专家高置信分歧 165 个，
  **163 修正 / 1 破坏，精度 99.4%**；W40 70/70，W20 93/94。

  最终锁定后只跑一次。

## 2026-11-27 test 纪律修正（重要过程教训）

- **错误**：test 被用于 NMS、Soft-NMS、center 专家、multi 专家的多次
  确认，并启动了 combined test。这把 test 变成了开卷验证集，是
  test 泄漏；combined test 已停止，无结果。
- **规则**：所有变体/阈值/表征选择只在 fit/val；test 只在配置冻结后
  使用一次。若 test 已被多次查看，记录泄漏，后续不再用 test 做选择；
  test 数字只作确认，不是无偏 held-out 估计。
- **最终交付**：strict multi（test 0.748748/0.696353；
  val 0.771582/0.729247）。combined low+short 的
  val 0.773038/0.730657 作为 **val-only 候选**，未 test 确认；
  不再为它跑 test。
- 以后新想法先在 val 验证；只有真正的新锁定配置才允许一次 test，
  且必须预注册、不得用 test 结果挑变体。

### 2026-11-27 test 原则的最终表述

- **test 可以用于最终评分，但不能用于选择**：模型参数、pipeline
  超参数、阈值、窗口、变体、表征，全部在 fit/val 上确定。
- 配置在 val 上冻结后，跑一次 test 得最终分数；看到分数后不回头
  用 test 改配置。若需改动，先在 val 验证；新的 test 只能作为新的
  锁定评估，并明确记录 test 已被复用。
- 当前冻结配置：combined low+short（multi 20 ms + low0.28/8
  conf0.95 + short5ms conf0.9，SHARED，score≥0.3）；
  val **0.773038/0.730657**。所有超参数来自 val。
- 预注册：test 分数即使低于早先 strict multi 的 0.748748，也不
  回头用 test 选 strict；最终 pipeline 是 val 冻结的 combined。
  test 已被多次查看，最终分数只作确认、不是 pristine held-out。
