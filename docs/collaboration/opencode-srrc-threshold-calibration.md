# SRRC 同窗阈值校准复核

2026-11-23。分支 `work/srrc-gt-pilot-prep`。本轮只做 GT 分类：
复核幅度 CNN 的 AUC 优势，并在原训练侧按源组留出校准集，锁定
一个全局阈值后回到原 366 个 dev 比较。未接检测器，未使用 test。

## 0. 结论先行

- **AUC 复核成立**：B0 总体 AUC **0.6652**；幅度 CNN 三个 5 epoch
  种子为 **0.7330 / 0.7218 / 0.7004**，都高于 B0；clean/weak/strong
  分层也基本都高于 B0。
- **默认判决偏类是真的**：完整训练侧模型默认判 class11 的数量为
  B0 205/366，幅度 CNN 284 / 14 / 314；真实 class11 为 177。
- **但简单全局阈值校准没有迁移到 dev**：B0 从 0.6222 降到 0.6082；
  幅度三个种子从 0.6296/0.6434/0.6821 降到 0.6200/0.6349/0.6555。
  校准后的两类召回更平衡，但总体平衡准确率都变差。
- **排序信号仍在**：校准后的幅度 CNN 相对校准后的 B0 净改对
  **+9 / +9 / +17**，seed1731 的 McNemar p=0.043；但只有 1/3
  种子显著，不能当作稳定判决规则。
- **判断**：现在不应直接加窗或做符号恢复；先解决分数校准/迁移。
  高 AUC 只说明排序有信息，不说明一个绝对阈值能跨源组使用。

## 1. AUC 独立复核

用逐实例 CSV 的 `logit_11 - logit_10` 复算 ROC AUC。完整训练侧
模型在 366 个 dev 上：

| 幅度 CNN seed1729 | **0.7330** | 0.9179 | 0.6978 | 0.6894 |
| 幅度 CNN seed1730 | **0.7218** | 0.8772 | 0.7077 | 0.6621 |
| 幅度 CNN seed1731 | **0.7004** | 0.9033 | 0.6491 | 0.6505 |
| I/Q CNN seed1729 | 0.5866 | 0.6431 | 0.5673 | 0.5853 |
| I/Q CNN seed1730 | 0.5921 | 0.6130 | 0.6056 | 0.5764 |
| I/Q CNN seed1731 | 0.5924 | 0.6195 | 0.6244 | 0.5558 |

默认判决的 class11 预测数：

| 方法 | pred11 / 366 |
| --- | ---: |
| B0 | 205 |
| 幅度 seed1729 | 284 |

## 2. 校准协议

只从原训练侧（1,458 实例）按 `group_id` 留出校准集，历史 dev
完全不参与阈值选择。

| 项 | 数值 |
| --- | ---: |
| 划分种子 | 20261123 |
| 内层训练 / 校准 | **1,167 / 291** |
| group 数 | 1,005 / 254 |
| 校准集 class10/11 | 150 / 141 |
| 校准集 clean/weak/strong | 56 / 105 / 130 |
| dev class10/11 | 189 / 177 |
| dev clean/weak/strong | 71 / 114 / 181 |
| group 跨内层/校准 | **0** |

- 幅度 CNN：同一 TinyResNet、5 epoch、batch 8、lr 1e-3、
  seed 1729/1730/1731；只用内层训练集训练。
- B0：同一 53 维 `B0_unsync` 特征，只用内层训练集重拟合。
- 分数：`logit_11 - logit_10`（B0 用 `decision_function`）。
- 阈值：在校准集上最大化两类召回的平均；同分时取离 0 最近的
  阈值。阈值锁定后，用**同一权重**在原 366 个 dev 上评估。

## 3. 默认 vs 锁定阈值

### 3.1 总体

| 方法 | 阈值 | 默认 bal | 校准后 bal | 默认 recall 10/11 | 校准后 recall 10/11 | pred11 默认→校准 |
| --- | ---: | ---: | ---: | --- | --- | ---: |
| B0 refit | −0.392 | 0.6222 | 0.6082 ↓ | 0.561 / 0.684 | 0.392 / 0.825 | 204 → 261 |
| 幅度 seed1729 | +0.419 | 0.6296 | 0.6200 ↓ | 0.344 / 0.915 | 0.794 / 0.446 | 286 → 118 |
| 幅度 seed1730 | −0.218 | 0.6434 | 0.6349 ↓ | 0.519 / 0.768 | 0.354 / 0.915 | 227 → 284 |
| 幅度 seed1731 | −0.135 | 0.6821 | 0.6555 ↓ | 0.545 / 0.819 | 0.413 / 0.898 | 231 → 270 |

所有方法校准后总体平衡准确率都下降；校准把类比例拉向另一边，
但没有提高总体正确性。B0 也下降，说明不是 CNN 特有的问题。

另一个关键现象：完整训练侧幅度 seed1730 默认 pred11 只有 **14**，
在内层重训后变成 **227**；seed1731 从 **314** 变成 **231**。
B0 的 pred11 则稳定在 204–205。**CNN 的分数零点会随训练子集
大幅移动，默认偏类不是固定偏移**；这比“换一个阈值”更难处理。

## 4. 判断与下一步

1. **AUC 复核支持“幅度 CNN 有排序信息”**，但不支持“换一个全局
   阈值就能解决默认偏类”。绝对阈值跨源组迁移失败。
2. **B0 也受同样影响**：重拟合 B0 的默认 0.6222，校准后 0.6082。
   这说明问题在分数校准/源组分布，而不是 CNN 专属。
3. **先不要加窗或做符号恢复**。当前更值得做的是：
   - 用 **rank/quantile 阈值**匹配目标类先验，而不是绝对分数；
   - 用 **cross-fit / 更多校准组**（或 out-of-fold 分数）估计阈值，
     减少单次 291 例校准集的方差；
   - 试 Platt/isotonic 校准或按源组做分数标准化；
   - 同时稳定训练（学习率/BN/轮数），因为不同 seed 的分数零点
     差异很大。
4. 如果校准/迁移稳定后 strong 层仍是主要错误，再考虑 **16 窗**；
   符号恢复仍排在其后，历史证据（R_amp +0.94 pp、相位不稳、
   恢复率 36.9%）不支持把它当第一优先。
5. 本轮只到 GT 分类；检测器接入留待后续独立新样本验证。
